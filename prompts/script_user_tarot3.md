# タロット3択 User Prompt テンプレ

> **使い方**: `{}` の変数を実値に置き換えて Claude API の `user` メッセージに渡す。
> system は `prompts/script_system.md` 全文 (キャッシュ対象)。

---

```
date: {date}
genre: tarot3
theme: {theme}
seed: {seed}

このパラメータで、タロット3択ショート動画 (45〜55秒) の台本を生成してください。

具体的にしてほしいこと:
- hook はテーマ「{theme}」に直結した質問型または呼びかけ型
- body は次の流れ:
  1. テーマ提示 + 3枚のカードを直感で選ぶよう促す (5〜7秒)
  2. カードA (image_role: "card_a") を引いた人へのリーディング (8〜10秒)
  3. カードB (image_role: "card_b") を引いた人へのリーディング (8〜10秒)
  4. カードC (image_role: "card_c") を引いた人へのリーディング (8〜10秒)
  5. 共通の締めメッセージ (image_role: "reveal") (3〜5秒)
- cta はプロフィール固定リンクへ誘導、A8 電話占い案件 (例: 初回最大2,400円分無料) を念頭に
- caption は冒頭に #PR、ハッシュタグに #タロット #タロット3択 #占い #{theme} を含める

出力は必ず record_script tool で。
```

---

## 変数一覧

| 変数 | 例 | 備考 |
|---|---|---|
| `{date}` | 2026-04-26 | YYYY-MM-DD |
| `{theme}` | 片思いの行方 / 復縁の可能性 / 金運の流れ / 仕事運 / 人間関係 / 結婚のタイミング | テーマ語彙集は下記参照 |
| `{seed}` | 1729 | 再現性確保用の整数。日付ハッシュ等を使う |

## 推奨テーマ語彙集 (回せば1ヶ月分以上)

### 恋愛・対人

- 片思いの行方
- 復縁の可能性
- あの人の本音
- 二人の今後3ヶ月
- 出会いがある場所
- 結婚のタイミング
- 連絡したほうがいい?
- 今避けるべき人

### 仕事・金運

- 今の仕事の続け方
- 転職に良い時期
- 金運の流れ (今週)
- 副業で動くべき方向
- 上司との関係
- 苦手な人との距離

### ライフ・自己

- 今のあなたに必要なこと
- 手放すべきもの
- 近々訪れる変化
- 今やるべき一歩
- 直感で選んでいい?

## 注意

- 同じテーマを連投しない (アルゴリズム的に飽きられる)。1週間で同テーマは最大2回
- 「あの人」「彼/彼女」を限定しすぎず、視聴者の状況に当てはめやすい言い回しを優先
- カードA/B/C には具体的なタロット名 (例: 「太陽」「月」「世界」) を `body[].text` に登場させ、`prompts/image_tarot.md` でその名前を画像に描画させる
