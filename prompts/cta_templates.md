# CTA / キャプション テンプレ

> **使い方**: 動画ごとに以下から1つ選び、`{}` を実値に置換して `caption.txt` に保存。
> 必ず冒頭に `#PR` を置き、末尾に緩衝句を含める。

---

## 動画内 CTA (5秒分、`script.json` の `cta.text`)

### A. 一般 (どのテーマでも使える)

1. `気になる人は本格鑑定をプロフから ✨ #PR ※エンタメ目的`
2. `もっと深く知りたい人は固定リンクへ ☎️ #PR`
3. `あなただけの答えはプロフィールリンクから 🔮 #PR`

### B. A8電話占い案件特化 (初回無料訴求)

> 案件規約に従って **必ず最新の無料分** を確認してから具体数値を入れる。例は仮値。

1. `初回◯分無料の本格鑑定はプロフから 🌙 #PR ※エンタメ目的`
2. `今だけ初回最大◯,◯◯◯円分無料、リンクはプロフへ ✨ #PR`
3. `気になる方は無料登録から始められる本格鑑定をプロフから ☎️ #PR`

### C. テーマ特化 (タロット3択)

1. `恋愛の答えをもっと知りたい人はプロフィールから本格鑑定 💌 #PR ※娯楽目的`
2. `あの人の本音を聞ける本格鑑定はプロフから 🌙 #PR`
3. `あなた専用のタロットは固定リンクから 🔮 #PR`

### D. 12星座運勢

1. `あなたの星に合わせた本格鑑定はプロフから ⭐ #PR ※エンタメ目的`
2. `今日の運勢から一歩深く、本格鑑定はプロフへ 🌙 #PR`

## ハッシュタグ戦略

### 共通必須

- `#PR` (規制対応)
- `#占い`
- `#fyp` `#おすすめ` (TikTok / Reels の伸び補助、ただし入れすぎると逆効果なので2つまで)

### ジャンル別

| ジャンル | 推奨タグ |
|---|---|
| タロット3択 | #タロット #タロット3択 #タロット占い #タロットリーディング |
| 恋愛系 | #恋愛運 #片思い #復縁 #復縁占い |
| 仕事系 | #仕事運 #金運 #転職 |
| 12星座運勢 | #今日の運勢 #12星座 #星占い #ホロスコープ |

### 数

- TikTok / Reels: 5〜8個 (詰めすぎ逆効果)
- YouTube Shorts: 3〜5個 (本文1行以内)

### NG タグ

- `#当たる占い` の連投はアルゴリズム警戒対象になりがち。週2回程度に抑制
- `#最強占い` `#的中率No1` 等は景表法リスクで使わない

## 変数

| 変数 | 例 |
|---|---|
| `{theme_short}` | 片思いの行方 / 復縁 / 金運 |
| `{theme_tag}` | 片思い / 復縁 / 金運 (ハッシュタグ用、空白なし) |
| `{date_short}` | 4月26日 |
| `{linktree_url}` | https://linktr.ee/your_handle |

## 投稿前 最終チェック

- [ ] 冒頭200文字以内に `#PR` がある
- [ ] 「絶対」「100%」「必ず当たる」が含まれていない
- [ ] 緩衝句 (`※エンタメ・娯楽目的`) がある
- [ ] 18歳以上推奨の記載がある
- [ ] A8 案件規約に違反するハッシュタグ・表現がない
- [ ] TikTok の場合: キャプション内に **直URL** を貼っていない (= プロフィールリンク誘導のみ)
