# CTA / キャプション テンプレ

> **使い方**: アカウントの **Phase に応じて** 適切なセクションを選ぶ。
> Phase 判定基準は `docs/strategy.md` および `docs/launch_checklist.md` 参照。

| Phase | 期間 | リンク・PR表記 | 主CTA方針 |
|---|---|---|---|
| **Phase 1: ウォームアップ** | Day 1〜14 | bioリンクなし、`#PR`不要 | コメント誘導のみ、純エンタメ |
| **Phase 2: ソフト導入** | Day 15〜30 | Linktree仮設置、`#PR`は記載 | コメント誘導 + プロフ示唆 |
| **Phase 3: マネタイズ稼働** | Day 30〜 | A8リンク稼働、`#PR`必須 | 本格鑑定誘導 + コメント |

新規アカウントは必ず Phase 1 から始める (シャドウバン回避)。

---

## Phase 1: ウォームアップ期 (Day 1〜14、リンクなし)

### 動画内 CTA (`script.json` の `cta.text`)

1. `結果はピン留めコメント👇 選んだ◯◯はコメントで💌`
2. `あなたが選んだのは? コメントで教えてね 🔮`
3. `みんなのコメント、見てみて👇 結果はピン留めコメントに`

末尾に「※エンタメ目的」のみ。`#PR` は **付けない** (広告活動していない期間は不要)。

### キャプション本文 (タロット/3択共通)

```
{theme_short}、直感で1枚選んだ?

A・B・C のうちピンときた1枚にメッセージを込めました 🔮
結果はピン留めコメントに👇

選んだ◯◯はコメントで教えてくださいね 💌

※エンタメ・娯楽目的のコンテンツです
※18歳以上推奨

#タロット #タロット3択 #占い #黒猫占い #今日のメッセージ #fyp #おすすめ
```

### Phase 1 のピン留めコメント (リンクなし版)

```
🔮結果発表🔮

A→太陽☀️ 不安が晴れて明るい流れに乗っていく時が近いかも
B→月🌙 違和感こそが大切なヒントに
```

> Phase 1のポイント: A8リンクや「本格鑑定」の言及は **一切しない**。純粋に占いを楽しむ場として運営し、フォロワーとの信頼関係を築く期間。

## ハッシュタグ戦略 (全Phase共通)

### 必須

- `#占い`
- `#fyp` `#おすすめ` (TikTok / Reels、2つまで)

### Phase別の `#PR`

- Phase 1: 付けない (広告活動なし)
- Phase 2-3: 必ず付ける (キャプション冒頭200文字以内)

### ジャンル別タグ

| ジャンル | 推奨タグ |
|---|---|
| タロット3択 | #タロット #タロット3択 #タロット占い #タロットリーディング |
| 恋愛系 | #恋愛運 #片思い #復縁 #復縁占い |
| 仕事系 | #仕事運 #金運 #転職 |
| 12星座運勢 | #今日の運勢 #12星座 #星占い #ホロスコープ |
| 動物別 | #黒猫占い #うさぎ占い #狐占い #フクロウ占い … (cast.yaml参照) |

### 数

- TikTok / Reels: 5〜8個 (詰めすぎ逆効果)
- YouTube Shorts: 3〜5個 (本文1行以内)

### NG タグ

- `#当たる占い` の連投はアルゴリズム警戒対象になりがち。週2回程度に抑制
- `#最強占い` `#的中率No1` 等は景表法リスクで使わない

## 投稿前 最終チェック (Phase別)

### Phase 1 (ウォームアップ)

- [ ] 「絶対」「100%」「必ず当たる」が含まれていない
- [ ] 緩衝句 (`※エンタメ・娯楽目的`) がある
- [ ] 18歳以上推奨の記載がある
- [ ] **bio内/キャプション内/コメント内すべてにリンクがない**
- [ ] **「本格鑑定」「プロフから」などのアフィリ示唆が一切ない**
- [ ] `#PR` をつけていない (広告活動なしのため不要)

### Phase 2 (ソフト導入)

- [ ] 上記Phase 1チェック (リンク禁止項目以外) に加えて
- [ ] 冒頭200文字以内に `#PR` がある
- [ ] Linktree URL がbioに正しく設置されている
- [ ] キャプション内に直URLは **貼っていない**
- [ ] A8リンクがLinktreeにあれば案件規約遵守

### Phase 3 (マネタイズ稼働)

- [ ] 上記Phase 2チェックすべて
- [ ] A8 案件規約に違反するハッシュタグ・表現がない
- [ ] 動画内CTAが「初回◯分無料」など案件の最新訴求と整合
