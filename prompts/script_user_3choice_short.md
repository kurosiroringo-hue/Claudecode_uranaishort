# 3択ショート (動物占い・15秒・コメント誘導型) User Prompt テンプレ

> **使い方**: `{}` の変数を実値に置き換えて Claude API の `user` メッセージに渡す。
> system は `prompts/script_system.md` 全文 (キャッシュ対象)。
> 出演動物は `config/cast.yaml` で定義された active キャストから1体選ぶ。

---

## ベーステンプレ

```
date: {date}
seed: {seed}
performer: {animal_id}            # cat / rabbit / fox / ... (cast.yaml の active キーと一致)
tool: {tool_jp}                    # タロットカード / パワーストーン / アンティーク鍵 / ...
choice_a: {choice_a_jp}           # 例: 太陽 / ローズクォーツ / 古い鉄鍵
choice_b: {choice_b_jp}
choice_c: {choice_c_jp}
theme: {theme}                    # 例: 今あなたに必要なメッセージ / 片思いの行方
signature_sound: {signature_sound_text}   # 字幕/コメントで表現する鳴き声 (例: にゃおー🐈、コーン🦊)

このパラメータで「動物占い・15秒・コメント誘導型」の台本を生成してください。

構成 (厳守):
- hook (2秒): 動物が画面に出て「直感で1枚、選んで🔮」など短い呼びかけ。視聴者の指を止める一撃
- body[1] (2秒): 「A、B、C…ピンときたのは?」3つの選択肢を並べる紹介
- body[2] (6秒): ナレなし区間。字幕は「…直感で…決めて…」のみ。BGMで緊張感を作る間
- body[3] (3秒): {signature_sound_text} で締める。ナレなし、SE と字幕のみ
- cta (2秒): 字幕「結果はピン留めコメント👇 #PR」のみ

合計 15秒。

出力で必須:
- caption.text_short (TikTok/Reels用、冒頭に #PR、末尾に ※エンタメ・娯楽目的 と ※18歳以上推奨)
- pinned_comment.text (TikTok/Reels/Shorts投稿後にピン留めする本文。各選択肢の意味を1〜2行で。末尾に「選んだカードはコメントで💌」「本格鑑定はプロフから #PR」)
- hashtags は {animal_hashtag} を必ず含める

NG:
- 「絶対」「必ず」「100%」「必ず当たる」「治る」「儲かる」
- 結果を断定する語尾 → 「〜になりそう」「〜のヒントが見えるかも」「〜への一歩」

出力は record_script tool で。
```

## 変数

| 変数 | 例 | 取得元 |
|---|---|---|
| `{date}` | 2026-04-26 | 当日の日付 |
| `{seed}` | 1729 | 整数 (再現性用) |
| `{animal_id}` | cat / rabbit / fox | `config/cast.yaml` の active キー |
| `{tool_jp}` | タロットカード / パワーストーン / アンティーク鍵 | cast.yaml の `tool` |
| `{choice_a_jp}` etc. | 太陽 / ローズクォーツ / 月の鍵 | テーマ・動物に合わせて選定 |
| `{theme}` | 今あなたに必要なメッセージ / 片思いの行方 | `prompts/script_user_tarot3.md` のテーマ語彙集を流用 |
| `{signature_sound_text}` | にゃおー🐈 / きゅうー🐇 / コーン🦊 | cast.yaml の `signature_sound` |
| `{animal_hashtag}` | #黒猫占い / #うさぎ占い / #狐占い | cast.yaml の `hashtag` |

## 動物 × ツール × 選択肢の組み合わせ例

### 黒猫 × タロット
- 太陽 / 月 / 星 (希望系)
- 恋人 / 運命の輪 / 世界 (運命系)
- 力 / 星 / 節制 (整え系)
- 戦車 / 魔術師 / 太陽 (前進系)

### うさぎ × パワーストーン
- ローズクォーツ / アメジスト / シトリン (愛/直感/金運)
- ムーンストーン / ラピスラズリ / ターコイズ (内省/真実/旅)
- ガーネット / アクアマリン / ペリドット (情熱/平穏/再生)

### 狐 × アンティーク鍵
- 月の鍵 / 太陽の鍵 / 星の鍵 (古鍵に各シンボル彫刻)
- 銅の鍵 / 銀の鍵 / 金の鍵 (素材で運気を表現)
- 古い鍵 / 細い鍵 / 重い鍵 (形で人生フェーズを表現)

選択肢は **「3者で性格が明確に違う」** ものを選ぶ。
似たもの同士だと視聴者が選びにくい → コメント率が落ちる。

## 投稿時の運用

1. 同じ動画で3プラットフォーム共通投稿
2. **投稿後すぐに自分でピン留めコメント**を貼る
3. 最初の30分のコメント (`私A!` 等) に絵文字1個でいいから返信 (アルゴリズム対策)
4. ピン留めコメントは編集可。誤字に気付いたら遠慮なく直す

---

## 量産メモ

同じ動物カット4枚で30本作れる:

- 日替わりでテーマを変える (恋愛・仕事・対人・金運・自己)
- 日替わりでカード/ストーン/鍵の組み合わせを変える
- ピン留めコメントの読み解きはバリエーションを持たせる (`config/tarot_deck.yaml` 等から拾う)

3匹×30本 = **90本のストック** を画像素材だけで作れる計算。
