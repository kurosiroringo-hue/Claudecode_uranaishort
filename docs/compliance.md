# コンプライアンス (compliance.md)

## このドキュメントの位置づけ

本プロジェクトは **占い** という嗜好性ジャンル × **アフィリエイト** という広告活動の組み合わせ。
法令・各プラットフォーム規約に違反するとアカウントBAN/案件報酬没収/最悪は措置命令につながる。
**台本生成プロンプト** と **最終チェックスクリプト** の二層で必ず守る。

---

## 1. ステマ規制 (景品表示法 不当表示告示 第20号、2023年10月施行)

### 要件

事業者から提供を受けた広告は、それが広告であることを **一般消費者が容易に判別できる形で明示** する必要がある。判別不可能な広告 = ステルスマーケティング = 景表法違反 (措置命令対象)。

### 本プロジェクトでの実装

- 動画キャプション/概要欄の **冒頭** に必ず以下のいずれかを記載:
  - `#PR`
  - `#広告`
  - `#プロモーション`
  - 「広告を含みます」
- 動画内テロップでも、CTA直前に小さく `※広告を含みます` を表示するとなお安全
- ハッシュタグの末尾ではなく、**冒頭または最初のハッシュタグ群** に置くこと (消費者庁ガイドラインで「容易に認識できる位置」を要求)

### 検査ロジック (compliance_check.py M2以降)

```python
PR_TAGS = ["#PR", "#広告", "#プロモーション", "広告を含みます", "[PR]"]
if not any(tag in caption[:200] for tag in PR_TAGS):
    raise ComplianceError("PR表記が冒頭200文字に存在しません")
```

## 2. 景品表示法 (優良誤認・有利誤認)

### NG表現リスト (台本/キャプションともに禁止)

#### 断定・確実性

- 「絶対」「必ず」「100%」「確実に」「間違いなく」
- 「当たる占い」「必ず当たる」「的中する」 → 「気づきが得られる」「ヒントになる」等に置換
- 「未来が決まる」「運命が分かる」 → 「今のあなたへのメッセージ」に置換

#### 効能・効果の保証

- 「金運が上がります」 → 「金運の流れが見えてきそう」
- 「復縁できます」 → 「復縁のヒントが見えるかも」
- 「願いが叶います」 → 「願いに近づく一歩になりそう」

#### 比較優位

- 「業界No.1」「日本一当たる」「最強の占い師」
- 数値根拠のない「満足度95%」等

### 緩衝句のテンプレ

すべてのリーディング末尾に以下のいずれかを自然に挿入:

- 「※エンタメ・娯楽目的のコンテンツです」
- 「あくまで一つの参考として」
- 「最終的な判断はあなた自身で」

## 3. 薬機法 (医薬品医療機器等法)

### NG (健康・身体への効能を匂わせる表現)

- 「不眠が治る」「うつが軽くなる」「体調が良くなる」
- 「痩せる」「肌がきれいになる」
- パワーストーン/オラクル系で「免疫力アップ」「治癒力」

占いコンテンツでは健康訴求は基本不要なので、**触れない** が最も安全。

---

## 4. 特定商取引法 / 個人情報保護法

- 占い結果から具体的な投資・株・FX・ギャンブル指南へ繋げない (金融商品取引法/有利誤認リスク)
- 視聴者の個人情報 (生年月日・名前) を募集する形式は避ける。やる場合は外部の正規鑑定サービス (= A8案件) へ誘導する形に留める

---

## 5. 未成年保護

- 18歳未満を主たる対象にした金銭的サービス (電話占い・チャット占い) の誘導は不適切
- 動画冒頭または概要欄に「18歳以上推奨」を明記すると安全

## 6. 各プラットフォーム規約のポイント

### TikTok

- 占い・スピリチュアルは **規約上は許容** (Mystic/Spiritualカテゴリあり)
- ただし以下は厳禁:
  - 病気の治癒を主張するスピリチュアル療法
  - 投資/ギャンブル成功を約束する占い
  - 「呪い」「悪霊」を煽って恐怖を与え金銭を要求するパターン
- 外部リンクはプロフィールURLのみ許可 (動画キャプション内のURLは規約違反/シャドウバン対象)

### YouTube Shorts

- 医療誤情報ポリシーに抵触しないよう、健康関連の言及は避ける
- 概要欄のアフィリエイトリンクは可。冒頭に `#PR` を必ず
- 自動再生対象なので冒頭3秒の音量設計は重要

### Instagram Reels

- ブランデッドコンテンツツールを使うとなお良い (ただし任意)
- 「商品紹介」タグ機能は無関係 (占いはサービスのため)
- リンクはプロフィールのみ。Linktree経由推奨

## 7. A8.net 案件規約

A8の電話占い系案件には個別規約がある。**必ず案件詳細ページで確認** すること。よくある制約:

- 自己アフィリエイト不可
- リスティング広告不可 (動画内SEO/ハッシュタグは許容範囲だが規約要確認)
- ブランド名 (例: 「ヴェルニ」) を不適切に使用しない
- 比較・順位表示NGの案件もある

成果が大きい案件ほど規約も厳しい傾向。**案件規約を `docs/compliance_a8_<案件名>.md` に転記** して常に参照できる状態にすること (M1運用時の手作業)。

## 8. チェックリスト (1動画ごとに通す)

- [ ] キャプション冒頭200文字以内に `#PR` (or 広告表記) がある
- [ ] 台本に「絶対」「100%」「必ず当たる」等の禁止語が **ない**
- [ ] 健康/治療の言及が **ない**
- [ ] CTA末尾に「※エンタメ・娯楽目的」等の緩衝句がある
- [ ] 18歳以上推奨が概要欄またはテロップにある
- [ ] A8案件個別規約に違反していない
- [ ] 動画キャプション内に直リンクURLが **ない** (TikTok対応)

このチェックリストは M2 で `compliance_check.py` として正規表現実装する。
