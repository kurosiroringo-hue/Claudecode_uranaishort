# 戦略 (strategy.md)

## アカウントコンセプト

**「占い動物園」 — 主役の黒猫🐈を中心に、様々な動物たちが日替わりで占いをする。最後に各動物が鳴いて締める。**

- **主役**: 黒猫 (タロット担当・月間投稿の約4割を占める)
- **サポートキャスト**: 白うさぎ (パワーストーン)・狐 (アンティーク鍵)・フクロウ (月相)・カラス (ルーン)・ハリネズミ (ハーブ/木の実)・柴犬 (おみくじ) … 順次拡張
- **占いツール**: タロット・星座・パワーストーン・キャンドル・アンティーク鍵・ルーン・月相・ハーブ・花・おみくじ など、**視覚で楽しめる** 占いだけを採用 (数字占い等のテキスト系は不採用)
- 全動画が **同一の15秒コメント誘導型フォーマット** で統一
- 動画末尾の鳴き声 (にゃおー・きゅう・コーン・ホーホー…) が **アカウントのブランドサウンド** になる
- 結果はピン留めコメントで開示 → コメント率と再視聴率を最大化

キャスト定義は `config/cast.yaml`、占いツール定義は `config/tools.yaml`、本動画用テンプレは `prompts/script_user_3choice_short.md`。

## コンテンツマトリクス (動物 × ツール × テーマ)

ほぼ無限の組み合わせを生む3軸構成:

| 軸 | 数 | 例 |
|---|---|---|
| **動物** | 7体 (拡張可) | 黒猫・うさぎ・狐・フクロウ・カラス・ハリネズミ・柴犬 |
| **ツール** | 11種 (拡張可) | タロット・星座・パワーストーン・キャンドル・鍵・ルーン・月相・古文書・ハーブ・花・木の実・おみくじ |
| **テーマ** | 30+ | 片思い/復縁/金運/対人/転機/手放し/今日のメッセージ … |

理論値: 7 × 11 × 30 = **2,310** ユニーク動画。実運用で動物×ツールの相性 (`cast.yaml` の `compatible_tools`) を尊重しても **数百本** のストックが組める。

### 推奨される動物 × ツール の相性 (主なもの)

| 動物 | 一押しツール | 相性ツール |
|---|---|---|
| 🐈 黒猫 (主役) | タロット | キャンドル・星座・鍵 |
| 🐇 白うさぎ | パワーストーン | ハーブ・キャンドル・花 |
| 🦊 狐 | アンティーク鍵 | タロット・ルーン・キャンドル |
| 🦉 フクロウ | 月相 | 古文書・ルーン・キャンドル |
| 🐦 カラス | ルーン | 古文書・鍵 |
| 🦔 ハリネズミ | ハーブ | 花・パワーストーン・木の実 |
| 🐕 柴犬 | おみくじ | 鍵・ハーブ |

クロスオーバー (例: 黒猫×キャンドル、ハリネズミ×パワーストーン) は **意外性の演出** として月1〜2回入れる。

## ゴール

A8.net 電話占い系案件 (ヴェルニ・エキサイト電話占い・ココナラ電話占い等) の **新規無料分** 訴求で、月10件以上の成果発生を3ヶ月以内に達成する。

## ターゲット

- **第一ターゲット**: 20〜40代女性、恋愛/対人/仕事の悩みあり、夜間スマホ滞在時間長い
- **第二ターゲット**: 30〜50代女性、生活の節目 (結婚・転職・子育て) で意思決定に迷っている
- 配信時間帯: 21:00〜24:00 をメインに、朝7:00〜8:30 (出勤前の今日の運勢需要)

## メインフォーマット: 15秒・コメント誘導型 (Comment-Driven Short)

| 秒 | 内容 | 役割 |
|---|---|---|
| 0-2 | フック「直感で1枚、選んで🔮」(動物登場) | 指を止める |
| 2-4 | 「A、B、C…ピンときたのは?」(3アイテム提示) | 興味喚起 |
| 4-10 | アイテムがアップ、選ぶ時間 (ナレなし、字幕「…直感で…決めて…」) | 視聴者に選択させ、滞在時間を作る |
| 10-13 | 動物が鳴いて締め「にゃおー🐈」(SE強め) | ブランドサウンド・離脱防止 |
| 13-15 | 字幕「結果はピン留めコメント👇 #PR」 | コメ欄へ誘導 |

= 15秒、4カット、ピン留めコメントに各選択肢の意味を記載。

### この設計が強い理由

| 指標 | 効果 |
|---|---|
| 動画完了率 | 60〜70% (TikTok最重要指標を満たす) |
| コメント率 | 5〜10% (アルゴリズム評価が桁違いに上がる) |
| 平均視聴時間 | 動画15秒+コメ閲覧で20秒超 |
| 制作工数 | 1日3〜5本量産可能 |
| シリーズ性 | 「今日はどの動物?」で再来訪を生む |

## 補助フォーマット: 12星座・今日の運勢 (30〜45秒)

朝の日課コンテンツとしてフォロワー定着用。動物キャラを1体ピックアップして「今日の◯◯座 + ◯◯動物のメッセージ」というクロスオーバーも有効。

## 投稿運用

3プラットフォーム (TikTok / Reels / Shorts) に **同一動画を同時投稿**。ピン留めコメントは投稿後すぐ自分で貼る (詳細は `docs/operations.md`)。

### 1日3本のローテーション例 (`config/cast.yaml` の `posting_rotation_example` 参照)

| 時間帯 | 担当 (例: 月曜) | 狙い |
|---|---|---|
| 朝 7:30 | 🦔 ハリネズミ × ハーブ「今日の癒しメッセージ」 | 朝の癒し枠、フォロワー定着 |
| 夜 21:30 | 🐈 **黒猫 × タロット**「片思いの行方」 | 主役・主力CV枠 |
| 夜 23:00 | 🦉 フクロウ × 月相「近々訪れる変化」 | 深夜の深掘り需要 |

### 時間帯と動物の相性 (cast.yaml の posting_time_recommend より)

- **朝枠**: ハリネズミ・うさぎ・柴犬 (癒し系・親しみやすさ)
- **夜枠 (主軸)**: 黒猫 (恋愛・主力CV)
- **深夜枠**: フクロウ・カラス (シリアス・神秘性が強いテーマ)

### 黒猫主役のリズム維持

- 月間投稿の **約4割を黒猫** に割く (`cast.yaml` の `posting_share`)
- 週に最低3本は黒猫を入れる (アカウントの顔としての認知強化)
- サムネイル/アイコンは黒猫を中心に統一感を作る

## フック設計 (2〜3秒勝負)

| 種類 | 例 |
|---|---|
| 直接呼びかけ | 「ちょっと止まって、選んで🔮」 |
| 質問 | 「ピンときたのはどれ?」 |
| 限定感 | 「今この動画を見たあなたへ」 |
| キャラ任せ | 動物の表情アップだけで0.5秒持たせて、テロップで一発 |

NG: 「絶対」「必ず」「100%」を含むフック (景表法違反リスク)。

## サムネ/カバー設計

- TikTokは1コマ目がそのままカバー → **動物の顔が大きく映る hook カット** を1枚目に
- 中央〜上部に大きい日本語テキスト (太ゴシック、白縁取り黒)
- 配色: ダークネイビー × ゴールド (`prompts/image_style_anchor.md` 準拠)
- 動物の絵文字 (🐈🐇🦊) をテキストに混ぜると視認性UP

## アカウント設計

### 1アカウント・複数キャスト戦略 (推奨)

- TikTok / Instagram / YouTube それぞれ **同名のアカウントを1つずつ** 取得
- 全プラットフォームで同じ動画を同時公開 (**マルチプラットフォーム同期**)
- 動物キャストは追加・退場可能。1キャストにつき4〜6カットの素材があれば30本ストック可能 (テーマ・選択肢を入れ替え)

### NGパターン

- キャスト1体ごとに別アカウントを作る (= ジャンル特化が薄まりアルゴリズム評価↓、運用負荷↑)
- 動物キャラを増やしすぎる (キャストは同時に最大5体まで。多すぎると視聴者の認知が散る)

## CTA (誘導文) 方針

- 動画内では断定せず「結果はピン留めコメント👇」「本格鑑定はプロフから #PR」のみ
- プロフィール固定リンクで A8リンクへ (TikTok は外部リンク制限ありのため Linktree 経由推奨)
- A8電話占い案件は **「初回◯分無料」** が最強訴求 → ピン留めコメントの末尾に必ず明記

## KPI (M1〜M3)

| 指標 | M1終了時 (1週) | M2終了時 (3週) | M3終了時 (5週) |
|---|---|---|---|
| 累計投稿数 | 21本 (1日1本) | 63本 (1日3本) | 105本 |
| 動画完了率 (15秒形式) | 50% | 60% | 65% |
| コメント率 | 3% | 6% | 8% |
| プロフィールアクセス率 | 2% | 4% | 5% |
| A8経由クリック | 50 | 200 | 500 |
| A8成果発生 | 0〜1件 | 3件 | 10件 |

## 改善サイクル

- 毎週日曜にプラットフォーム分析画面+A8管理画面を確認
- 動画完了率50%未満のキャスト/テーマは即休止、上位3本を量産元に複製
- フックの差分テスト (A/B): 同じ本編で冒頭2秒だけ変えた版を作り比較
- 鳴き声SE はキャラごとに1〜3種類用意してA/B (どの音が一番ループ視聴を生むか測る)

## 拡張ロードマップ

| Phase | 期間 | 内容 |
|---|---|---|
| **Phase 1** | M1〜M3 | 黒猫主軸 + うさぎ・狐の3体で運用開始。タロット/パワーストーン/鍵の3ツール。月10件成果 |
| **Phase 2** | M4以降 | フクロウ・カラス・ハリネズミ・柴犬を順次投入。月相/ルーン/ハーブ/おみくじを追加し全11ツール展開 |
| **Phase 3** | 軌道乗り後 | クロスオーバー (黒猫×キャンドル等の意外な組み合わせ)、季節モチーフ (バレンタイン特別占い・お盆・年末)、コラボ動画 (複数動物が登場) |
| **Phase 4** | 規模拡大 | 海外展開 (英語字幕版、動物は万国共通で通じやすい)、ライブ占い、グッズ展開 |

## 新ツール導入のフロー

新しい占いツールを追加するときの手順:

1. `config/tools.yaml` に定義追加 (3択構造を必ず満たす)
2. `prompts/image_<tool>.md` を作成 (style anchorを継承)
3. **黒猫で1本テスト投稿** (主役の認知力を借りて反応を見る)
4. 完了率50%超 / コメント率3%超 なら他キャストへ展開
5. 反応が悪ければそのツールはお蔵入り (執着しない)
