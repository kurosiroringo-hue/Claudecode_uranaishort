# ローンチチェックリスト (Day 0〜30+)

新規アカウントを **シャドウバンせずに最短でマネタイズに到達** させるための運用フロー。
詳細戦略は `docs/strategy.md` の「アカウント運用フェーズ」セクション参照。

---

## Day 0 (準備日・約1時間)

### 素材入手

- [ ] BGM をDOVA-SYNDROMEから 3曲ダウンロード
  - 検索キーワード「神秘」「ヒーリング」「ファンタジー」
  - 黒猫向け (暗め) / うさぎ向け (やわらか) / フクロウ向け (月夜) で雰囲気を分ける
  - 配置: `assets/bgm/mystic_cat.mp3` `assets/bgm/soft_rabbit.mp3` `assets/bgm/moonlit_owl.mp3`
- [ ] 動物の鳴き声SE を効果音ラボから入手 (https://soundeffect-lab.info/sound/animal/)
  - `assets/se/cat_meow.wav` (猫の鳴き声)
  - `assets/se/rabbit_squeak.wav` (うさぎは「子どもの動物」カテゴリから代替)
  - `assets/se/owl_hoot.wav` (フクロウ)
- [ ] `assets/bgm/LICENSE.md` に出典を記録

### アカウント名決定

- [ ] 候補を3〜5案リストアップ (例: `@uranai_doubutsuen` `@uranai_zoo` `@mofu_uranai`)
- [ ] **3プラットフォーム (TikTok/Instagram/YouTube) で同名取れるか検索**
- [ ] 同名で取れない案は捨て、最終1案を確定

## Day 1 (アカウント取得・音声追加)

### アカウント開設 (3プラットフォーム)

- [ ] TikTok アカウント作成
  - プロフィール画像: 黒猫の hook カット
  - bio: **リンクなし** で以下のテキスト
    ```
    🐈🐇🦊 占い動物園
    黒猫タロット/うさぎパワーストーン/フクロウ星読み
    結果はピン留めコメント👇
    ※エンタメ目的
    ```
  - カテゴリ: エンタメ / ライフスタイル
- [ ] Instagram アカウント作成 (同名・同bio)
  - プロのアカウントに切り替え (カテゴリ: エンターテインメント)
- [ ] YouTube アカウント作成 (同名)
  - チャンネルアート: 動物3匹のシルエット入りバナー (任意)
  - About: 同bio

### 既存3動画に音声+字幕を追加

各 `output/2026-04-26/{cat,rabbit,owl}_001/` で以下を実施:

- [ ] BGM を ffmpeg で重ねる (volume 0.18)
- [ ] 動物の鳴き声SE を該当タイミング (動画末尾の鳴き声カット) に重ねる (volume 1.4)
- [ ] 字幕 (`subtitles.ass`) を焼き込む
- [ ] **ナレーションは Phase 1ではスキップ** (字幕+SEで十分機能)
- [ ] 出力 `master.mp4` を確認 (ffprobeで 1080x1920/30fps/15秒/H.264 検証)

### 投稿用メタデータ準備

各動画の `caption.txt` と `pinned_comment.txt` が **Phase 1版 (リンクなし、#PRなし)** であることを確認。
不安なら `prompts/cta_templates.md` の「Phase 1: ウォームアップ期」セクションを参照して上書き。

## Day 2 (1本目投稿)

### 投稿手順 (TikTok → Reels → Shorts の順)

- [ ] **21:30前後** に TikTok から投稿 (Phase 1の固定投稿時刻)
- [ ] caption.txt の内容をキャプション欄に貼り付け
- [ ] 公開ボタン
- [ ] **公開直後にすぐ自分でコメント欄に pinned_comment.txt の内容を貼り付け**
- [ ] そのコメントを長押し → 「ピン留め」
- [ ] Instagram Reels に同じ master.mp4 をアップ、同じcaptionで投稿
- [ ] YouTube Shorts に同じ master.mp4 をアップ、タイトル+概要欄を設定

### 投稿後30分の運用

- [ ] 寄ってきたコメント (「私A!」等) に絵文字1個でいいから返信 (アルゴリズムスコア向上)
- [ ] 8時間後に再生数チェック (TikTok の初動目安)

---

## Day 3〜7 (連続投稿期)

- [ ] 毎日21:30に1本投稿 (3プラットフォーム同時)
- [ ] 投稿時刻は前後30分以内を死守
- [ ] 並行して **次の7本を制作** (黒猫4本 + うさぎ2本 + 狐 or ハリネズミ1本)

### Day 5〜7: A8申請

- [ ] A8.net 登録 (https://www.a8.net/)
- [ ] 「占い」「電話占い」で検索、案件3つに提携申請
  - 推奨: ヴェルニ / エキサイト電話占い / ココナラ電話占い
- [ ] 申請時にTikTokアカウントURLを「サイトURL」欄に提出
- [ ] 承認まで3〜7日 (Phase 2移行とちょうど同期)

---

## Day 8〜14 (Phase 1 完了に向けて)

- [ ] 連続投稿継続
- [ ] フォロワー50人到達を目指す
- [ ] 完了率50%、コメント率3%が出ているかチェック
- [ ] 出ていないテーマ・動物は早めに見直し

### Phase 1 終了判定

- [ ] フォロワー50人以上 **または** Day 14到達
- [ ] A8 案件提携1つ以上承認 (理想)
- [ ] OK なら Phase 2 へ

---

## Day 15〜30 (Phase 2: ソフト導入期)

### Linktree 設定

- [ ] Linktree 無料アカウント作成 (https://linktr.ee/)
- [ ] リンク追加:
  - 「📞 本格鑑定はこちら」 (A8リンク、承認済みなら)
  - 「📷 Instagram」「🎥 YouTube」 (相互送客)
  - 「💌 お問い合わせ」 (メールフォームか公式LINEなど)
- [ ] Linktree URL を 3プラットフォームの bio に追加

### キャプション・ピン留めコメント切替

- [ ] 各動画の `caption.txt` を `prompts/cta_templates.md` の **Phase 2版** に書き換え (`#PR` 追加・「プロフから」追加)
- [ ] 各動画の `pinned_comment.txt` の末尾に `本格鑑定はプロフから #PR` を追加

### 連続投稿継続

- [ ] 1日1本ペースを死守
- [ ] フォロワー300〜500人を目指す
- [ ] プロフィールクリック率4%超 を目指す

---

## Day 30+ (Phase 3: マネタイズ稼働)

### 切替

- [ ] A8リンクが Linktree のトップに来るよう順序入れ替え
- [ ] 動画内CTAを **Phase 3版** に切替 (`prompts/cta_templates.md` 参照)
  - 「初回◯分無料の本格鑑定はプロフから🌙 #PR」など案件特化文言に
- [ ] ピン留めコメント末尾に **A8 訴求の具体数値** (初回◯分無料、最大◯円分等) を明記

### 投稿頻度を1日2〜3本に増やす (任意)

- 黒猫21:30 / うさぎ朝7:30 / フクロウ深夜23:00 の三本立て
- A8成果が安定したら投資価値あり

---

## 全期間共通の守ること (毎日)

- [ ] 投稿後30分以内のコメント返信 (絵文字でも可)
- [ ] 動画完了率の確認 (TikTok/IG/YT analytics)
- [ ] 投稿時刻の固定 (アルゴリズム重視)
- [ ] ハッシュタグは5〜8個 (詰め込みすぎない)
- [ ] キャプション内に **直URLを貼らない** (TikTokシャドウバン対象)

---

## 全期間共通の禁止事項

- ❌ Phase 1中に「本格鑑定」「プロフから」「#PR」を口走る
- ❌ Day 1から bioにアフィリエイトリンクを貼る
- ❌ 1日に同じ動画を3プラットフォームに3回投稿 (1本/日でOK、同時投稿は可)
- ❌ 「絶対」「100%」「必ず当たる」「治る」などの断定/効能訴求
- ❌ 投稿後にキャプションを大幅編集 (アルゴリズム再評価リセット)
- ❌ A8案件規約違反 (リスティング広告併用、自己アフィリエイト等)

---

## トラブル対応

| 症状 | 対処 |
|---|---|
| TikTok 1本目が100再生未満 | 投稿時刻見直し (21:30 ± 30分) / フックの2秒目改善 |
| コメントが0件 | ピン留めコメント文の末尾「コメントで教えてね💌」が抜けてないか確認 |
| シャドウバン疑い (急に再生数が10分の1) | bioリンク削除、3日休止、Phase 1からやり直し |
| A8申請却下 | 投稿数が足りない可能性。10本以上投稿してから再申請 |
