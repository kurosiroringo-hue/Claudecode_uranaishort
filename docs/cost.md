1日3本×30日のうち約30本がキャッシュミス想定として、月+¥27 程度の差。**実質無視できる**。

## コスト圧縮オプション (必要時)

### 1. 画像生成のハイブリッド化

文字なし純背景カット (例: `04_reveal` の手元演出) を Gemini 2.5 Flash Image ($0.039/枚) に切替。
6枚中3枚を Gemini に置換 → 1本あたり $0.42 → $0.32 ≒ ¥48 (-¥18/本、月-¥1,620)

### 2. 画像枚数の削減

タロット3択を 6枚 → 4枚に簡略化 (hook / cards統合 / reveal / cta) → 1本あたり ¥42 (-¥24/本)

### 3. Claude モデルダウングレード

`claude-haiku-4-5` に変更すれば台本コストはさらに下がるが、占い特有のニュアンス・コンプライアンス遵守の安定性で **Sonnet 4.6 を推奨**。

### 4. 量産体制でのキャッシュ最大化

連続生成すれば cache hit が維持されコスト削減。1日のうち2回 (朝/夜) に分けず、まとめて1回で全テーマ生成→ローカル保存→投稿予約 が最も安い。
