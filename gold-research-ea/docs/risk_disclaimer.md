## 利益を保証しません

- このEAを使用して **利益が出ることを一切保証しません**
- バックテストで良好な結果が得られた場合でも、それは将来の収益を約束しません
- 過去のチャートでうまくいったロジックがフォワード環境 (実弾運用) で同じ成績を再現する保証はありません

## FX/CFD 取引の主要リスク

| リスク | 内容 |
|--------|------|
| 価格変動リスク | ゴールド (XAUUSD) は1日5%以上動くこともある高ボラ銘柄 |
| レバレッジリスク | 預入証拠金を超える損失が生じる可能性 (ロスカット未達時) |
| ロスカットリスク | 急変時にロスカットが滑り、想定以上の損失が出ることがある |
| スプレッド/スリッページ | 重要指標発表時はスプレッドが10倍以上に開くこともある |
| 週末ギャップ | 金曜クローズと月曜オープンの間で大きく窓を開けることがある |
| 流動性リスク | 早朝アジア時間や祝日は約定価格が不利になりやすい |
| システムリスク | EA/MT5/ブローカーサーバの障害で意図しない取引が発生する可能性 |
| 規制リスク | 国・地域によりレバレッジ規制やCFD取引規制が変わる |

## SNS で見かける「必勝手法」「高勝率」主張への注意

本EAが参照する戦略のうち EMA 系は X (旧Twitter) 投稿から着想を得ている。
**投稿者の主張する成績は次の理由で鵜呑みにすべきでない**:

1. **小サンプル**: 「N=35 で勝率78.4%」は95%信頼区間が約 [64%, 90%] と非常に広く、真の勝率が50%でも35試行で78%以上出る確率は無視できない
2. **生存バイアス**: 勝った瞬間のスクショだけがSNSに流れる。負けトレードは投稿されない
3. **期待値 ≠ 勝率**: 勝率80%でも、勝ち1pip×80% − 負け10pip×20% = -1.2pip で負け越す
4. **コスト未考慮**: スプレッド・スワップ・スリッページを差し引くと結果は変わる
5. **アフィリエイト/集客動機**: 自慢ポストは情報商材・ブローカーアフィリエイトへの導線である場合がある

このEAの目的は、こうした主張を **自分のバックテスト環境で再現して真偽を確認する** ことにある。再現できなければ正直に「再現せず」と記録する。

## 推奨する使い方

1. まずデモ口座で十分にテストする (最低3ヶ月)
2. バックテストはアウトオブサンプル期間で評価する (パラメータ最適化に使った期間で評価しない)
3. リアル運用は **失っても生活に影響しない金額** で始める
4. 月次パフォーマンスを記録し、設計時の前提から乖離したら停止する
5. 勝っている時こそレバレッジを上げない
6. 損切りルールを EA 任せにせず、自分でも理解しておく

## 使用しない方がよい状況

- 借入金や生活費・教育資金を投じる
- 「短期間で大きく増やしたい」と焦っている
- レバレッジ・証拠金・ロスカットの仕組みを理解していない
- メンタル/体調が万全でない (徹夜明け、強いストレス下)
- 重要指標 (FOMC、米雇用統計、CPI) 発表直前
