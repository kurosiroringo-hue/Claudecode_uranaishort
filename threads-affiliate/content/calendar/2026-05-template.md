## 投稿生成フロー

1. このカレンダーの各行を `automation/generate-post.md` の入力 JSON に変換
2. Claude API で投稿生成
3. コンプラ通過した投稿のみ `content/posts/YYYY-MM-DD-NN.md` に保存
4. 投稿予約ツール (Threads ネイティブ or Buffer 等) に投入
5. 投稿日に Threads に公開
6. 24時間後にエンゲージメント測定 (Threads Insights)
7. 翌週日曜に CSV 化して `analyze-weekly.md` に投入
