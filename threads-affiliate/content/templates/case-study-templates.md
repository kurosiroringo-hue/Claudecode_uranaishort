# Case Study テンプレ集 (case-study-templates.md)

数値公開型 (口座残高・家計簿・収益) は **信頼形成最強**。3パターン × 各5サンプル = 15投稿例。

> 全サンプル500字以内。コンプラチェック済。
> 数値はすべて仮置き。実運用時は **本人の実数** に置き換えること。

---

## 1. 証券口座・投資 数値公開型

### 構造

「[期間] / [入金額] → [評価額]」を1行目。
内訳・銘柄・所感を3〜5行で。
**必ず** リスク注記・運用成果保証なしを末尾に。

### サンプル 1-1

```
NISA 始めて14ヶ月、入金 42万円 → 評価額 47万8千円。

内訳:
・eMAXIS Slim 全世界株式: 30万入金 → 34万
・eMAXIS Slim S&P500: 12万入金 → 13.8万

増えた分は約5万8千円。+13.8%です。

ただ、これは「相場好調期」の数字。
リーマン級が来れば一時的に -30% もあり得ます。

私の戦略は「全世界1本、毎月積立、20年動かさない」
だけ。

考えない仕組みのほうが続いてます。

※運用成果は将来を保証しません。
```

### サンプル 1-2

```
iDeCo 始めて2年、入金 12万円 → 評価額 13万1千円。

(月5,000円から開始)

正直、iDeCo は地味です。
2年で +1万1千円、年利4%程度。

でも私が iDeCo を続ける理由は、節税。

年収400万円台の私の場合、
iDeCo 月5,000円 × 12ヶ月 = 60,000円 が
所得控除になり、年 約 9,000円 の節税。

「投資の利回り」+「節税」のダブル取りで、
実質 年利10%超の効果。

※税効果は所得・自治体で変動します。
```

### サンプル 1-3

```
30代独身の金融資産、3年間の推移を晒します。

(年末時点)
2023年: 200万円
2024年: 320万円 (+120万、貯金100万 + NISA20万)
2025年: 480万円 (+160万、貯金80万 + NISA80万)

伸びた要因:
①固定費見直しで月3万浮かせた
②先取り貯金の金額を月5万→8万に上げた
③NISA を月3万→月5万に増額

「派手な手法」は何もないです。
仕組みを作って、
自動で貯まる導線にした結果。
```

### サンプル 1-4

```
楽天証券で1年運用してみた率直な感想。

(月3万 × 12ヶ月積立、つみたて投資枠)

良かった点:
・楽天ポイントで投資できる
・アプリが見やすい
・楽天市場とのポイント連携で家計が見える

微妙だった点:
・取扱商品は SBI のほうが多い
・キャンペーンの条件変更が頻繁

総合: 楽天経済圏の人なら相性良し。
それ以外は SBI のほうが無難かも。

※私個人の感想です、判断は各自で。
```

### サンプル 1-5

```
NISA 「成長投資枠」を使ってみた1年経過。

枠消費: 240万円分 (全世界株 + 米国ETF)
評価額: 264万円 (+10%)

つみたて枠 (月3万) と並行運用してます。

成長枠の使い方:
・ボーナスでまとめ買い (年2回)
・暴落時にスポット買い

つみたて枠だけだと「機械的」、
成長枠を併用すると「ちょっと考える」運用になりました。

初心者にはつみたて枠1本で十分、
慣れてから成長枠の活用も検討して OK です。

※運用成果は将来を保証しません。
```

## 2. 家計簿・支出 数値公開型

### 構造

「[月]の家計、晒します」。
収入・固定費・変動費・貯金額を一覧で。
**改善点・気づき** を最後に。

### サンプル 2-1

```
4月の家計、晒します。

【収入】
給与手取り: 26万円

【固定費】合計 9.8万円
家賃: 7万円
通信費 (楽天モバイル): 2,000円
保険 (掛け捨て): 3,000円
サブスク (Netflix・Spotify): 2,400円
水道光熱: 12,000円
ジム: 6,000円

【変動費】合計 8.2万円
食費: 4万円
日用品: 1万円
交際: 2万円
趣味: 1.2万円

【貯金】8万円 (先取り)

固定費を 10万円以下に抑えるのが個人的目標。
来月は通信費はさらに見直し予定。
```

### サンプル 2-2

```
1年間の家計を集計しました。

【年収】
手取り: 312万円 (月26万 × 12)
ボーナス手取り: 80万円
合計: 392万円

【支出】
固定費 (年): 117.6万円
変動費 (年): 98.4万円
合計支出: 216万円

【貯蓄+投資】
貯金: 96万円
NISA: 60万円
iDeCo: 6万円
合計: 162万円

貯蓄率: 41.3%。

ボーナスを「特別な月」にせず
普段の倍ペースで貯金口座に入れる仕組みが効きました。
```

### サンプル 2-3

```
独身一人暮らし、固定費の最適化結果。

【見直し前】
家賃: 8万 / 通信: 8,000 / 保険: 18,000 / サブスク: 9,800
合計: 11.6万円

【見直し後】
家賃: 8万 (変えず) / 通信: 2,000 (楽天モバイル) /
保険: 3,000 (掛け捨て) / サブスク: 2,400 (2本に絞る)
合計: 8.74万円

差額: 月 28,600円、年 343,200円。

NISA に回せる原資が、1日かけて生まれました。

固定費の見直しは「年に1回の投資」だと思ってます。
```

### サンプル 2-4

```
食費を月4万→2.5万に下げた手順。

【元の状態】
平日昼: 外食 (700円 × 20日 = 14,000円)
平日夜: 自炊 + たまに外食 (15,000円)
土日: 外食多め (11,000円)
合計: 4万円

【変えたこと】
・お弁当持参 (週3 → 週5)
・水筒持参 (コンビニコーヒー断ち)
・週1のご褒美ランチは残す
・土日の外食を「月3回まで」に制限

【現在】
合計: 2.5万円

「全部我慢」じゃなく
「週1のご褒美は残す」が続くコツでした。
```

### サンプル 2-5

```
30代独身、年間の貯蓄&投資を公開。

(2025年実績)

【貯蓄】
給与天引き先取り: 60万円
ボーナスから: 50万円
小計: 110万円

【投資 (NISA + iDeCo)】
つみたて枠: 36万円
成長枠 (ボーナス): 24万円
iDeCo: 6万円
小計: 66万円

【合計】176万円 / 年

手取り 392万円中の 45%。
派手な節約はなし、固定費の最適化だけ。

「自動で動く仕組み」を作るのが、
凡人でもできる貯め方でした。
```

## 3. 副業・収益 数値公開型

### 構造

「[期間] [副業種類] [収益額]」を1行目。
内訳・労力・所感を必ずセットで。
「楽して稼げる」感を出さず、地味な実態を見せるのが信頼の鍵。

### サンプル 3-1

```
副業ブログ、24ヶ月運営した収益。

【月別推移 (税抜)】
1ヶ月目: 0円
3ヶ月目: 320円 (Google AdSense)
6ヶ月目: 8,400円
12ヶ月目: 31,500円
24ヶ月目: 82,000円

【労力】
1日30分 × 月25日 = 月12.5時間
時給換算: 24ヶ月目で約6,560円/h

正直に言うと、最初の半年はほぼ無収入。
「半年は耐える前提」で始めるのが現実的です。

※私の場合の数字、再現性は人によります。
```

### サンプル 3-2

```
4月のアフィリエイト収益、晒します。

【発生】合計 192,000円
A8.net: 132,000円 (FX口座 8件)
もしも: 28,000円 (クレカ 4件)
楽天アフィ: 32,000円 (物販 30件相当)

【承認・確定】(発生から2-3ヶ月遅れ)
2月発生分の確定: 84,000円

正直なポイント:
・発生 ≠ 入金 (承認率 約65%)
・確定までタイムラグ2-3ヶ月
・案件選定で承認率が大きく変動

「即金で稼げる」イメージとはギャップあります。
```

### サンプル 3-3

```
副業3年目、年間収益を公開。

【年間収益 (税抜き発生額)】
ブログ AdSense: 38万円
アフィリエイト: 96万円
note 有料記事: 24万円
合計: 158万円

【労力】
平均 1日30分 × 360日 = 180時間
時給換算: 約 8,778円/h

【経費】
サーバー: 18,000円
書籍・教材: 50,000円
カフェ代: 50,000円

【粗利】 約 146万円

3年積み上がるとここまで来ますが、
1年目は10万、2年目は60万でした。
複利は本業より遅い、けど確実に効きます。
```

### サンプル 3-4

```
自己アフィで副業デビューした最初の3ヶ月。

【1ヶ月目】合計 32,000円
証券口座開設 (SBI): 8,000円
クレカ発行 (楽天): 6,000円
ポイ活 (案件3件): 3,000円
銀行口座開設: 5,000円
保険無料相談: 10,000円

【2ヶ月目】合計 18,000円
クレカ追加 (三井住友NL): 8,000円
動画サブスク無料体験: 3,000円
ポイ活: 7,000円

【3ヶ月目】合計 8,000円
(自分で開設できる案件は枯渇)

合計 58,000円を3ヶ月で。
労力は週2時間程度。

「お金が動く感覚」を掴むには十分でした。
```

### サンプル 3-5

```
note の有料記事、1年間の販売実績。

【販売数 (1記事)】
1ヶ月目: 12部 (× 1,000円 = 12,000円)
3ヶ月目: 8部 (× 1,000円 = 8,000円)
6ヶ月目: 5部 (× 1,000円 = 5,000円)
12ヶ月目: 3部 (× 1,000円 = 3,000円)

合計: 約 92部、92,000円。

【労力】
記事執筆: 約20時間
更新・改善: 月2時間 × 12ヶ月 = 24時間

時給換算: 約 2,090円/h

note は「月初の集中投稿で固定客」を作るより、
「質の高い1本を長く育てる」ほうが私には合いました。

※私の場合の実績、内容で大きく変動します。
```

## 4. Case Study 型を書くときのコツ

### Do

- **数字は具体に**: 「月10万」ではなく「月82,400円」レベル
- **悪い数字も出す**: 「1ヶ月目は0円」など
- **労力をセットで**: 時給換算 or 月間時間を明記
- **税前/税後を明示**: 発生 / 承認 / 入金 の違いを書く
- **再現性の限界**: 「私の場合」「人によります」を必ず

### Don't

- 派手な数字だけ抜粋 (信頼を失う)
- 「楽して」「誰でも」「簡単に」(景表法 NG)
- リスク・労力の隠蔽
- 月収 100万 などの瞬間最大値の連発

### 投稿前 セルフチェック

- [ ] 数字が具体的か (千円単位以下まで)
- [ ] 「悪い数字」「失敗期間」も書いてあるか
- [ ] 労力 (時間 or 期間) が明示されているか
- [ ] 「個人差があります」「再現性は」の注記があるか
- [ ] 投資・副業文脈で `#PR` が必要かチェック (案件名が出る場合は付与)
- [ ] 500字以内
