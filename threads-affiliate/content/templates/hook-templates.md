# Hook テンプレ集 (hook-templates.md)

Threads は **1行目で 95%が決まる** プラットフォーム。スクロール中に親指を止めさせるためのフック10種と、各5サンプル投稿。

> 全サンプルは 500字以内。コンプラチェック済 (「絶対」「必ず儲かる」等の禁止語なし)。
> 投稿時の `#PR` 付与判断は `compliance-checklist.md` 参照。

---

## 1. 数字断言型 (Number-Hook)

### 構造

「[具体的な数字] + [自分の状態 or 結果]」を1行目に置く。数字が具体的なほど信頼される。

### サンプル 1-1

```
入社2年目の私の貯金、
給料日に残ってた「8,372円」だった。

毎月「今月こそ貯める」って言って、
給料日に欲しい服を買って、スタバ行って、飲み会行って、
気づいたら通帳が空。

転機は「先取り3万円」を別口座に動かす設定だけ。
意志力じゃなくて、仕組みに頼った瞬間に、
1年で40万貯まった。

意志が弱いんじゃなくて、
仕組みがなかっただけ。
```

### サンプル 1-2

```
家計簿アプリを3つ、合計2,847日記録した結果、
私が手放せた支出は「サブスク7本」だった。

Netflix・Amazon Prime・Spotify・週刊誌アプリ・
ジム (3ヶ月行ってない)・コンビニコーヒー定額・電子書籍読み放題。

合計、月12,800円。
年間で 153,600円。

「使ってないけど、解約が面倒」が積もると、
これくらい消える。

サブスク棚卸し、おすすめです。
```

### サンプル 1-3

```
NISA始めて1年、入金32万円、
評価額が 36万8千円になりました。

増えた分は約4万8千円。
+15%です (※相場好調時、平常時はもっと低いはず)。

ただ、これは「結果オーライ」で、
私の戦略が上手かったわけじゃない。

「全世界株式インデックス1本、毎月積立」
これだけ。

考えない仕組みのほうが、
私は続きました。

※運用成果は将来を保証しません。
```

### サンプル 1-4

```
30歳までの貯金 0円から、
3年で「420万円」貯めた手順を、
ぜんぶ晒します。

①固定費の見直し (月-3万)
②先取り貯金の自動化 (月+5万)
③ボーナス手取りの50%貯金
④NISA で投資へスライド

派手なことは何もしてない。
給料も平均的な会社員レベル。

「派手じゃない方法」のほうが、
普通の人には続きます。
```

### サンプル 1-5

```
1日の食費を 800円 → 350円に下げたら、
月13,500円浮きました。

具体的にやったこと:
・お弁当 (前日の残り物 OK)
・水筒で麦茶
・コンビニ寄り道を 週0回
・週1のご褒美ランチは残す

「全部我慢」だと続かないので、
「日常を下げる + 週1は残す」がバランスでした。

無理しない節約、
あなたの生活でもできそうな箇所、ありますか?
```

## 2. 逆張り型 (Counter-Intuitive Hook)

### 構造

世間の通説の逆を1行目で打ち、「え、なぜ?」と続きを読ませる。論拠が弱いと炎上するので、必ず根拠を3行目までに提示。

### サンプル 2-1

```
家計簿、つけなくていいです。

正確には、「月に1回だけ口座残高を見る」で十分。

家計簿アプリで毎日入力してた頃、
私はたぶん年間120時間使ってた。
時給1,500円換算で 18万円分の労力。

やめてから、貯金スピードは変わらなかった。
理由は「先取り貯金が自動化されてた」から。

入力じゃなくて、仕組みでお金は貯まります。
```

### サンプル 2-2

```
NISA、急いで満額やらなくていいです。

「年間360万円使い切らないと損」って言う人いるけど、
360万円を投資に回せる会社員、
そんなに多くない。

私の場合、最初の1年は月1万円から。
2年目で月3万、3年目で月5万。

無理して満額にして、
急な出費で取り崩すほうがダメージ大きいです。

自分のペースで OK。
```

### サンプル 2-3

```
副業より、固定費の見直しが先です。

副業で月3万円稼ぐのに必要な労力と、
保険・通信費・サブスクの見直しで月3万円浮かす労力、
後者のほうが圧倒的に小さい。

私は副業始める前に、
・格安SIMに変更 (月-5,000円)
・保険見直し (月-7,000円)
・サブスク7本解約 (月-12,800円)

合計 月-24,800円。
これを「副業の代わり」と捉えれば、
すでに月3万近い改善です。
```

### サンプル 2-4

```
「貯金より投資」は、初心者には罠です。

理由はシンプルで、
生活防衛資金がない状態で投資すると、
急な出費で「安値で売る」事故が起きるから。

私の場合、生活費6ヶ月分 (約180万円) を貯めてから
NISA を始めました。

順番は「貯金 → 防衛資金 → 投資」。
焦って投資から始めると、
心が持ちません。
```

### サンプル 2-5

```
「節約はみみっちい」って思ってる人ほど、
実は浪費でストレス溜めてます。

私もそうでした。
「ケチは恥ずかしい」と思って外食・タクシーを正当化、
気づくと月収の40%が消費に。

節約じゃなくて、
「自分が本当に好きなことに使う」発想に変えたら、
ストレスが減りました。

サブスク7本解約 → 月1の好きなレストラン1回。
合計支出は減って、満足度は上がりました。
```

## 3. 問いかけ型 (Question Hook)

### 構造

1行目を読者への質問で始める。読者の脳が答えを探し始め、続きを読ませる。

### サンプル 3-1

```
「貯金が増えない理由」、
本当に「給料が低いから」だと思いますか?

私はそう思ってました。
でも入社5年で給料が1.6倍になっても、
貯金は増えなかった。

理由は「給料が増えると、生活レベルも上がる」から。
これを「ライフスタイル・インフレ」って言います。

給料アップ時に、
固定費を上げない決意をするだけで、
貯金は加速します。
```

### サンプル 3-2

```
「老後 2,000万円」、
あなたの場合いくら必要か計算したことありますか?

実は、独身か既婚か、持ち家か賃貸かで、
必要額は大きく変わります。

私は30代独身賃貸で計算したら、
2,000万円じゃなくて
「2,800万円」が現実的でした。

ぼんやり不安より、
具体的な数字のほうが向き合いやすい。

計算手順、コメントで質問もらえれば共有します。
```

### サンプル 3-3

```
「副業」と聞いて、
最初に思い浮かぶのは何ですか?

物販? Webライター? せどり?
私は最初、ぜんぶ試して挫折しました。

挫折した理由を分析したら、
共通点は「初期投資 or 時間投資が大きすぎ」だった。

今、続いてるのは
・自己アフィ (=自分で口座開設してキャッシュバック)
・ポイ活 (家事の合間)
・ブログ (1日30分だけ)

「小さく始める」を3回失敗してから学びました。
```

### サンプル 3-4

```
「NISA、何から買えばいい?」って聞かれたら、
私は1つしか答えません。

「全世界株式インデックス」。

理由は、初心者が迷ってる時間が一番もったいないから。
完璧な銘柄を3ヶ月かけて選ぶより、
75点の銘柄で3ヶ月運用するほうが伸びる。

慣れてから個別株や新興国に分けても遅くないです。

最初の1本、迷ってる人いますか?
```

### サンプル 3-5

```
「副業バレが怖くて始められない」人、いますか?

私もそうでした。
でも調べたら、住民税の納付方法を「自分で納付」にすれば、
ほぼバレません。

ほぼ、と書いたのは、
本業の給料以上を副業で稼ぐと
住民税の額で気づかれるリスクがあるから。

月3〜5万円の副業なら、
税務処理を正しくやれば心配いらない範囲です。

(税理士さんに最終確認をおすすめします)
```

## 4. 告白型 (Confession Hook)

### 構造

「実は私、〜です」と弱さ・恥ずかしさを開示。心理的距離を一気に縮める。

### サンプル 4-1

```
実は私、3年前まで
リボ払いの残高 47万円ありました。

買い物が好きで、毎月の支払いが楽になる気がして、
リボ払いに切り替えてました。

気づいたら金利15%。
利息だけで月5,800円消えてた。

完済した方法はシンプルで、
①ボーナスで一括返済
②カード作り直し (リボ機能なし)
③現金主義に半年戻す

恥ずかしいけど、
過去の私と同じ人がいたら、
脱出はできます。
```

### サンプル 4-2

```
正直に言うと、
私のFIRE は無理かもしれません。

理由は2つ。
①現在の入金力では70歳までかかる
②本業を辞める覚悟がそこまで強くない

それでも「yuru-FIRE」を目指すのは、
完全リタイアじゃなくて、
「働き方を選べる状態」が欲しいから。

完璧なFIREは無理でも、
「週3勤務」「リモート専業」を選べる側に
立ちたい。

そのための yuru です。
```

### サンプル 4-3

```
告白します。
家計簿アプリ、3回挫折してます。

マネーフォワード、Zaim、おかねのコンパス。
全部、最初の2週間は完璧、
1ヶ月後には開かなくなる。

意志が弱いんだなと諦めかけたとき、
「家計簿はつけなくていい」と気づきました。

代わりに、
・先取り貯金を自動化
・固定費を年1回見直し
・残った分は使ってOK

これだけで、貯金スピード変わらずでした。
管理しないことで、続いてます。
```

### サンプル 4-4

```
本当のことを言うと、
副業で「楽して稼ぐ」を信じてた時期があります。

「Twitter運用で月100万」とか、
「ブログで自動収入」とか、
そういう情報商材に5万円使った過去あり。

結果、ぜんぶ続かなかったのは、
「楽して」の部分を信じすぎたから。

今は「地味に時間をかける」を受け入れて、
1日30分のブログを2年続けてます。

楽な方法、私には合いませんでした。
```

### サンプル 4-5

```
私、
過去にネット銀行の暗証番号を3回間違えて
ロックされたタイプです。

何が言いたいかというと、
「投資って ITに強い人がやるものでしょ?」
って思ってた人 (=過去の私) でも、
今 NISA で資産運用できてます。

スマホでログインさえできれば、
あとは月1回画面を見るだけ。

ITが苦手でも始められます、
本当に。
```

## 5. 失敗自虐型 (Self-Roast Hook)

### 構造

1行目に自分の失敗・無知をユーモラスに開示。「自分もそうだ」の共感と笑いを呼ぶ。

### サンプル 5-1

```
20代前半、私の老後対策は
「宝くじ」でした。

iDeCo? NISA? 401k?
全部「漢字3文字以上は無理」とスルー。

毎週300円の宝くじを20年買ったら、
合計31万円。

仮に同じ金額をインデックス投資してたら、
30年後、約78万円になってた計算 (年5%試算)。

宝くじから卒業して NISA に変えただけで、
将来の安心が変わります。

※将来の運用成果を保証するものではありません。
```

### サンプル 5-2

```
「保険でお金が増えると思ってた」時代、
私にはありました。

20代の頃、貯蓄型保険に月2万円。
「銀行より利率いい」って言われて、
10年で240万円積み立てました。

10年経って解約返戻金は、
220万円でした。

そう、減ってた。

保険は守るためのもの、
増やすのは投資。

20代の私に、教えてあげたい。
```

### サンプル 5-3

```
副業で月100万稼げる
って Twitter で見て、
情報商材に5万円課金した私です。

中身は「副業 100の方法」みたいな PDF で、
ググれば出てくる内容ばかり。

返金交渉して半額戻ってきましたが、
2.5万円は授業料になりました。

学んだのは
「再現性のある副業は、地味で時間がかかる」
ということだけ。

派手な広告ほど、警戒したほうがいいです。
```

### サンプル 5-4

```
30歳になるまで、
クレジットカードの「リボ払い」と「分割払い」の違い、
分かってませんでした。

リボは残高に対して金利、
分割は支払い回数で金利。

リボを使ってた当時、
金利15%で47万円残ってて、
利息だけで月5,800円。

恥ずかしい話ですが、
お金の知識は大人になってから
誰も教えてくれない。

知らないと、こうなる。
```

### サンプル 5-5

```
証券口座を開く前に、私は
「証券会社=怪しい」というイメージでした。

「銀行の定期預金が一番安全」と信じてて、
NISA も 5年スルー。

5年前に NISA を始めてた人と
今の私の金融資産差、
試算したら約180万円ありました。

「行動しなかったコスト」って、
こんなに大きい。

もし今 5年スルーしてる人がいたら、
今日が一番若い日です。
```

## 6. 結論先出し型 (Conclusion-First Hook)

### 構造

「結論: ○○です」「答えは○○」と1行目で答えだけ提示。理由を後から展開して納得させる。

### サンプル 6-1

```
結論: NISA は楽天証券か SBI 証券で OK。

理由は3つ。
①取扱商品が他社より多い
②手数料が業界最安水準
③スマホアプリが直感的

逆に「どっちか1つ」と聞かれたら、
楽天ポイントを使ってる人は楽天、
それ以外は SBI、
で実害はほぼなし。

3ヶ月迷うより、今日決めて始めるほうが、
資産形成は早いです。

※投資判断はご自身で。
```

### サンプル 6-2

```
答え: 副業を始めるなら、まず「自己アフィ」です。

理由は3つ。
①初期投資ゼロ
②即金性が高い (口座開設で1万円〜)
③税金処理の練習にもなる

私が最初に試したのは
証券口座の自己アフィで 8,000円。
2件目で FX口座開設 25,000円。

合計33,000円を1ヶ月で確保して、
「副業で本当にお金が動く感覚」を掴みました。

※自己アフィ可否は ASP の案件規約を要確認。
```

### サンプル 6-3

```
要するに、固定費は3つだけ見直せば終わります。

①通信費 (格安SIM化)
②保険 (掛け捨て化 or 解約)
③サブスク (使ってないもの解約)

これで月平均 1〜3万円浮きます。
私の場合は月24,800円。

家計簿で日々の支出と戦うより、
固定費1回の見直しのほうが、
労力対効果10倍くらい違います。

3つ、今週中にやれそうですか?
```

### サンプル 6-4

```
結論: 老後資金、独身は「2,800万円」が目安です。

(夫婦は 2,000万円が目安)

内訳:
・年金不足分 月8万円 × 25年 = 2,400万円
・医療・介護予備費 = 400万円
合計 2,800万円。

これを 30歳から準備するなら、
月3.5万円 × 30年積立 (年利4%試算) で
約 2,400万円。

足りない400万円は退職金やパートで補える計算。

※前提条件で大きく変動します、自分の数字で要試算。
```

### サンプル 6-5

```
答え: クレカは2枚で十分です。

①メイン: 還元率1%以上の年会費無料
②サブ: 特定店舗で還元率3%以上

それ以上持つと、
・年会費の管理が増える
・ポイント分散で価値が薄まる
・支出管理が複雑化

私は楽天カード + 三井住友(NL)の2枚運用で、
年間ポイント約42,000円分。

カードは多ければ得、ではないです。
「2枚に集中」が答え。
```

## 7. 比較型 (Comparison Hook)

### 構造

「Aの人、Bの人」「○○の場合と××の場合」と2軸を提示。読者は自分がどちらか考えて続きを読む。

### サンプル 7-1

```
「貯金が貯まる人」と「貯まらない人」、
3年見てきて、違いはたった1つでした。

差は「給料日にやることが違う」だけ。

貯まる人:
給料日に先取り貯金 → 残りで生活

貯まらない人:
1ヶ月の生活 → 残った分を貯金

順番が逆になるだけで、
3年後の貯金額は10倍以上変わります。

意志力の差じゃなくて、
順番の差。
```

### サンプル 7-2

```
NISA 楽天証券 vs SBI証券、
3年使ってみた率直な比較。

楽天:
・楽天ポイント投資が便利
・アプリが分かりやすい
・楽天市場ユーザーには圧倒的に楽

SBI:
・取扱商品が一番多い
・手数料がわずかに有利
・三井住友カード積立で1%還元

結論: 楽天経済圏の人 → 楽天、
それ以外で迷ったら → SBI。

優劣じゃなくて、相性。

※投資判断はご自身で。
```

### サンプル 7-3

```
「副業が続く人」と「続かない人」、
分岐点は1ヶ月目にあります。

続く人:
1ヶ月目で1円でも稼ぐ
↓
「お金が動く感覚」を掴む
↓
継続のモチベ確保

続かない人:
「完璧な準備」に1ヶ月使う
↓
1円も稼がず疲弊
↓
3ヶ月でフェードアウト

完璧より、まず1円。
私もそうでした。
```

### サンプル 7-4

```
20代と30代の貯金戦略、
私はこう変えました。

20代:
・収入を上げることに全振り
・副業・転職・スキル投資
・貯金は二の次でも OK

30代:
・支出の最適化に振り直し
・固定費見直し・サブスク整理
・運用に回す資金を増やす

20代で「節約」、30代で「収入UP」だと逆効果。
ライフステージに合った戦略を。
```

### サンプル 7-5

```
LINE家計簿派 vs エクセル家計簿派、
半年ずつ試した結果。

LINE家計簿派の私:
・続いた (3年継続中)
・データ集計が楽
・スマホで完結

エクセル家計簿派の昔の私:
・3週間で挫折
・PCを開く心理障壁
・カスタマイズで時間溶けた

「自分の生活動線にあるツール」が一番続きます。
ツール選びは「機能 < 動線」。
```

## 8. 損失強調型 (Loss-Aversion Hook)

### 構造

「○○しないと損」「○年で○万円消える」など、損失の具体額を1行目に。人は得より損に2倍敏感。

> 注意: 過度な恐怖訴求は信頼を落とすので、必ず「具体数字 + 解決策」をセットに。

### サンプル 8-1

```
リボ払いを5年使うと、
利息だけで「29万円」消えます。

(残高30万円・金利15%・最低支払いの試算)

29万円あれば、
NISA に積み立てて将来 80万円〜100万円になる金額。

私自身、リボで47万円残高あった時期があり、
完済までに14万円利息を払いました。

「毎月の支払いが楽」の代償が、
これくらい大きい。

リボ機能、今すぐ確認をおすすめします。
```

### サンプル 8-2

```
NISA、始めるのを5年遅らせると、
将来の資産が約 180万円減る計算です。

(月3万円・年利5%・複利30年で試算)

「もう少し勉強してから」が続いた5年は、
実は機会損失180万円。

完璧な戦略を5年磨くより、
75点の戦略で5年運用したほうが、
資産は大きくなります。

完璧主義、お金とは相性が悪い。

※運用成果は将来を保証しません。
```

### サンプル 8-3

```
スマホの大手キャリア、
3年使うと格安SIMより約 18万円 多く払ってます。

(大手 月7,000円 vs 格安 月2,000円 × 36ヶ月)

格安SIMの欠点は
・店舗サポートが薄い
・初期設定を自分でやる
くらい。

これに18万円払う価値があるかは、
人それぞれ。

私は払う価値を見出せず、
3年前に楽天モバイルに変えました。
```

### サンプル 8-4

```
使ってないサブスク、平均で月8,000円。
年間 96,000円が消えてます。

(複数調査の中央値)

私の場合、棚卸ししたら7本見つかって、
合計 月12,800円。

棚卸しの方法は簡単で、
クレカ明細を3ヶ月分だけ眺めるだけ。

「これ何だっけ?」が3つ以上あれば、
あなたも消える支出を抱えています。
```

### サンプル 8-5

```
保険、見直さないと10年で「60万〜120万円」損する可能性があります。

(過剰な貯蓄型 → 掛け捨て切替時の差額試算)

私は20代に貯蓄型保険を月2万、
10年で240万円払って、
解約返戻金 220万円。

掛け捨て (月3,000円) + NISA積立 (月17,000円) に
切り替えてれば、
資産は 約 280万円になってた計算。

差額60万円。
保険の見直しは、急いだ方がいい支出です。
```

## 9. ストーリー予告型 (Cliffhanger Hook)

### 構造

「これから話す」「最後まで読むと○○が分かる」を1行目に。続きが気になる脳科学的フック。

### サンプル 9-1

```
今から、私が貯金 0 → 420万円 にした
3年間の手順を、ぜんぶ晒します。

要点だけ先に。
①固定費見直し (月-3万)
②先取り貯金自動化 (月+5万)
③ボーナス手取りの50%貯金
④NISA で投資へスライド

「派手なこと何もしてない」のがポイント。

それぞれの詳細は別投稿で書きます。
気になる項目、コメントで教えてください。
```

### サンプル 9-2

```
これから話すのは、
「副業を3回挫折した私が4回目で続いた理由」。

1回目: 物販 (在庫管理で詰む)
2回目: Webライター (単価が低くて消耗)
3回目: 投資ブログ (アクセス0で凍る)

4回目で続いてる理由は、
「1日30分しかやらないルール」を作ったから。

詳細は次の投稿で。
3回挫折した過去がある人、
コメント教えてください ☕
```

### サンプル 9-3

```
最後まで読むと、
独身30代が老後資金「2,800万円」を準備する
具体ステップが分かります。

ステップは3つ:
①現状の年金見込みを「ねんきんネット」で確認
②不足額を計算 (公式テンプレあり)
③NISA + iDeCo で月3〜5万積立スタート

それぞれ別投稿で詳細書いていきます。
このスレッドを保存しておくと
迷ったときに辿れます。

※前提条件で変動、自分の数字で要試算。
```

### サンプル 9-4

```
今から書くのは、
「リボ払い 47万円を1年で完済した手順」。

恥ずかしい話を晒します。

①家計の全部を1ヶ月可視化
②ボーナスで一括返済
③リボ機能を解除して再発防止
④3ヶ月だけ現金主義に戻す

実体験ベースなので、
リボ抱えてる方には参考になるかも。

詳細は次の投稿で1つずつ書きます。
```

### サンプル 9-5

```
これから書くのは、
「FIRE は無理でも yuru-FIRE は射程内」という話。

FIRE = 完全リタイア (難しい)
yuru-FIRE = 働き方を選べる状態 (現実的)

私の試算では、
30代後半で月3万積立を続ければ、
50歳で「週3勤務」を選べるラインに到達できる。

完璧な FIRE じゃなくて、
「選べる側」を目指す設計、
詳しくは次の投稿で。
```

## 10. 反応誘発型 (Reaction-Inducing Hook)

### 構造

「○○な人、いますか?」「これに当てはまる方、コメント」など、明確に反応を求める1行目。

### サンプル 10-1

```
「節約のために最初にやめたこと」、
何でしたか?

私は「コンビニATMで現金を下ろすこと」でした。
手数料 220円 × 月3回 = 月660円。
1年で7,920円。
ATMネットで使えるネット銀行に変えるだけで消えた支出。

あなたが最初にやめたこと、
コメントで教えてください ☕
```

### サンプル 10-2

```
「副業で挫折した経験ある人」、
手を上げてください 🙋‍♀️

私は3回。
①物販、②ライター、③投資ブログ。

挫折した共通点は
「1ヶ月目で1円も稼げなかった」こと。

4回目 (自己アフィ)で1日で5,000円稼げて、
「お金が動く感覚」を掴めたら続きました。

挫折経験、共有してもらえると、
誰かの参考になります。
```

### サンプル 10-3

```
30代独身で
「老後不安あるけど、何していいか分からない」人、
いますか?

私もそうでした。
2年前まで、iDeCo を「言葉だけ」で済ませて、
実態を知らなかった。

行動した順番:
①ねんきんネットで見込み額確認
②NISA を月1万から始める
③iDeCo を月5,000円から始める

ぼんやり不安を、
具体的な数字に変えるだけで動けます。
```

### サンプル 10-4

```
「家計簿、続かない人」、
コメントで教えてください 🙋‍♀️

私は3回挫折しました。
マネーフォワード、Zaim、おかねのコンパス。
全部、最初の2週間は完璧、
1ヶ月後には開かなくなる。

家計簿をやめてから貯金スピードが落ちるかと思ったら、
全然変わらなかった。

「先取り貯金 + 月1の口座確認」で十分。

家計簿、無理にやらなくていいです。
```

### サンプル 10-5

```
「20代で投資始めなかったの後悔してる人」、
いますか?

私は最近気づきました。
20代の5年、銀行預金にしてた100万円。
NISA に入れてたら、
今ごろ約 130万円になってた計算。

差額30万円。
20代の私に教えてあげたい。

ただ、「今が一番若い日」なので、
30代の今からでも遅くないです。

※将来の運用成果を保証するものではありません。
```
