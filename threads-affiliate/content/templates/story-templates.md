# Story テンプレ集 (story-templates.md)

ストーリー型は「共感・ストーリー柱」の主軸。3パターン × 各5サンプル = 15投稿例。

> 全サンプル500字以内。コンプラチェック済。

---

## 1. Before/After 型

### 構造

「[過去のひどい状態]」 → 「[転機]」 → 「[現在の状態]」を3段で。

数字を必ず Before / After 両方に入れて変化を強調する。

### サンプル 1-1

```
Before: 給料日の3日後に通帳残高が3,247円。

「自分は意志が弱い」と諦めてた20代の私。
家計簿アプリ3つ挫折。

転機:
給料日に「3万円を別口座に動かす」自動設定だけ。
意志力じゃなく、仕組みに任せた。

After: 月10万円が勝手に貯まり、年間 120万円。

「貯金できない」じゃなくて、
「貯まる仕組みがなかった」だけ。
```

### サンプル 1-2

```
Before: リボ払い残高 47万円、利息で月5,800円消える状態。

買い物のたびに「楽な支払いだ」と思ってリボ。
気づいたら金利15%の沼。

転機:
①ボーナスで一括返済
②カード作り直し (リボ機能なし)
③3ヶ月だけ現金主義に戻す

After: リボ残高 0円、貯金 100万円突破。

利息で消えてた月5,800円が、
今は NISA に積み立てられてます。

恥ずかしい過去ですが、抜け出せます。
```

### サンプル 1-3

```
Before: 通信費 月7,800円、保険 月18,000円、サブスク10本。

「みんな払ってるから」で思考停止してた頃。

転機: 1日かけて見直し。
・楽天モバイルへ変更 (月-5,800円)
・掛け捨て保険に切替 (月-15,000円)
・サブスク7本解約 (月-12,800円)

After: 固定費 月33,600円減、年 403,200円浮く。

NISA に回せる原資ができたのは、
「日々の節約」じゃなく「固定費の1回見直し」でした。
```

### サンプル 1-4

```
Before: 30代独身、貯金 200万、漠然とした老後不安。

「2,000万円問題」を聞いて焦るけど、
何していいか分からない3年。

転機:
①ねんきんネットで自分の数字を確認
②独身の不足額を計算 (実は2,800万円必要だった)
③NISA 月3万 + iDeCo 月5,000円から開始

After: 不安が「数字」に変わって、向き合える状態に。

ぼんやり不安で2年溶かしたけど、
動き出した今、
「30代の今から間に合う」と分かりました。
```

### サンプル 1-5

```
Before: 副業3回挫折、合計5万円分の情報商材を購入。

「楽して稼ぐ」を信じてた頃。
物販・Webライター・投資ブログ、すべて挫折。

転機: 「1日30分しかやらないルール」を導入。

①自己アフィで初収入 (8,000円)
②ブログを1日30分だけ書く
③1ヶ月後に1万円、3ヶ月後に5万円

After: 副業歴2年、月平均8万円。

「楽して」じゃなくて
「続く範囲を決めて」が私には合ってました。
```

## 2. 失敗→学び 型

### 構造

「[失敗の具体]」 → 「[何を間違えたか]」 → 「[何を学んだか]」 を構造化。

失敗の具体性が信頼の鍵。「○○円損した」「○ヶ月無駄にした」など数字必須。

### サンプル 2-1

```
20代に貯蓄型保険で 20万円損した話。

月2万円の貯蓄型保険に10年加入。
240万円積み立てて、解約返戻金は 220万円。

何を間違えたか:
「銀行より利率いいですよ」の言葉を信じて、
保険と投資を混同したこと。

学び:
保険は「もしも」のためのもの。
増やすのは投資 (NISA・iDeCo)。

20代の私に教えてあげたい。
保険のセールスの「利率」、
銀行の利率と比較しちゃだめです。
```

### サンプル 2-2

```
副業で5万円課金した情報商材の話。

「Twitter運用で月100万」の広告に釣られて、
PDF教材を5万円で購入。
中身は「副業100の方法」みたいな汎用情報。

何を間違えたか:
「楽して稼げる」を信じすぎたこと。
派手な実績画像 = 再現性のある手順 ではない。

学び:
本当に稼げる副業は、
地味で時間がかかる。
派手な広告ほど警戒する。

授業料5万円。
2.5万円返金交渉できたのが救いでした。
```

### サンプル 2-3

```
家計簿アプリ 3個挫折した話。

マネーフォワード、Zaim、おかねのコンパス。
どれも最初の2週間は完璧、
1ヶ月後には開かなくなる。

何を間違えたか:
「家計簿をつければ貯まる」と思ってたこと。
実際は「先取り貯金」のほうが効果的。

学び:
私は「管理する」のが苦手なタイプ。
だから「管理しないで貯まる仕組み」を作った。

自分の弱さを否定するより、
弱さを前提に仕組みを作ったほうが続きます。
```

### サンプル 2-4

```
NISA を 5年スルーしてた後悔の話。

2018年に「NISA いいよ」と聞いてたのに、
「もう少し勉強してから」と言い続けて5年。

機会損失の試算:
月3万円 × 60ヶ月 × 平均年利5% =
本来なら 約 200万円超になってた計算。

何を間違えたか:
「完璧な戦略を組んでから始める」を選んだこと。

学び:
75点の戦略で5年動くほうが、
100点を5年探すより資産が大きい。

完璧主義はお金とは相性最悪です。

※運用成果は将来を保証しません。
```

### サンプル 2-5

```
リボ払い 47万円の地獄話。

買い物のたびに「リボ払いに変更」して、
気づいたら残高 47万円。
金利15%、利息だけで月5,800円。

何を間違えたか:
「毎月の支払いが楽 = お得」だと思ったこと。
実際は金利地獄で総支払額が膨れる。

学び:
クレカは1回払い or 2回払いまで。
リボ機能は「便利」じゃなくて「罠」。

この経験で14万円の利息を払いましたが、
「金融リテラシーの授業料」だと思ってます。
```

## 3. 1日のリアル 型

### 構造

「[起床]」「[午前]」「[午後]」「[夜]」など時系列で1日を切り出す。
読者が「私もこんな1日にしたい」と思える具体性を持たせる。

### サンプル 3-1

```
yuru-FIRE目指す経理OLの平日 (1日)

6:30 起床、白湯+トースト
7:30 出社 (徒歩通勤、運動兼)
12:00 弁当 (前日の残り物アレンジ)
18:00 退社、帰宅
19:00 副業ブログ 30分
19:30 自炊 (週末作り置きから)
20:30 NISA・家計簿チェック (5分)
22:00 読書 (図書館で借りた本)
23:00 就寝

派手なことは何もない。
「無理なく続く時間割」が yuru-FIRE の核です。
```

### サンプル 3-2

```
給料日の私のルーティン。

①スマホで給料振込確認
②3万円を貯金口座に自動移動 (先取り)
③5万円を投資口座に自動移動 (NISA積立)
④残りで生活
⑤ボーナス月のみ手取り50%を貯金口座

これだけ。

家計簿はつけない。
日々の支出を気にしない。
「先取りした残りは使ってOK」がルール。

意志力に頼らない設計が、
3年続いてる理由です。
```

### サンプル 3-3

```
土日の家計&投資チェック (合計15分)

土曜午前:
・ネット銀行残高 (1分)
・クレカ明細 (3分)
・サブスクで気になるもの確認 (2分)

日曜夜:
・NISA 評価額確認 (3分)
・週の支出ざっくり振り返り (3分)
・来週の家計予定 (3分)

これで終わり。

毎日家計簿アプリを開くより、
週末15分のほうが私には合ってました。
```

### サンプル 3-4

```
副業を続けるための「1日30分ルール」

朝活 (出社前):
6:30〜7:00 ブログ執筆 30分

これだけ。
「30分しか書かない」と決めると、
集中できて意外と300〜500字書ける。

夜は本業の疲れで書けないので、
「朝の30分」だけを死守。

完璧に2時間書こうとして3日でやめるより、
30分を365日続けるほうが、結果が出ました。

「続く時間」を決めるのが先です。
```

### サンプル 3-5

```
30代独身OLの「お金不安に向き合う」週末

土曜午前:
・ねんきんネット で年金見込み確認 (5分)
・楽天証券アプリで NISA 残高確認 (3分)

土曜午後:
・図書館でお金の本を1冊借りる
・カフェで30分読書 (お金 350円)

日曜午前:
・週の支出を5分でざっくり振り返り
・来週の予定 + ご褒美1つ決める

「ぼんやり不安」を「数字を見る習慣」に変えるだけで、
向き合える日々になりました。
```

## 4. ストーリー型を書くときのコツ

### Do (やる)

- **数字を入れる**: 金額・年数・回数。Before/After 両方に。
- **失敗の具体**: 「○○で失敗した」だけでなく「○○して○万円損した」まで。
- **時間軸を持たせる**: 「3年前は」「いま」など時系列が見える書き方。
- **小さな視点**: 「8,372円」「2,847日」など覚えにくい具体数字が信頼を生む。

### Don't (やらない)

- 「絶対」「必ず」など断定 (景表法・金商法 NG)
- 「楽して稼げました」など労力否定
- 「私にもできたから誰でもできる」など過度な一般化
- リスクを書かない投資ストーリー

### 投稿前 セルフチェック

- [ ] 1行目で読者が止まる強さがあるか
- [ ] Before / After どちらにも数字があるか
- [ ] 「学び」が一般化されてるか (=読者にも適用可能か)
- [ ] 投資・副業話なら「リスク」「個人差」の注記があるか
- [ ] 500字以内に収まっているか
