# List テンプレ集 (list-templates.md)

「○選」「やめたこと」「買ってよかった」型は **保存・シェア最強**。3パターン × 各5サンプル = 15投稿例。

> 全サンプル500字以内。コンプラチェック済。

---

## 1. ○選型 (3選/5選/7選)

### 構造

「[テーマ]の○選」を1行目、項目を箇条書きでリズム良く。
**3選**: 軽量、保存しやすい
**5選**: 標準、SEO的にも強い
**7選**: 完全網羅型、保存される
※5以下推奨。Threads では7項目はやや読みづらい。

### サンプル 1-1: 3選

```
NISA を始める前に、絶対やる「3選」

①生活防衛資金を6ヶ月分貯める
②楽天証券 or SBI証券で口座開設
③つみたて投資枠を月1万円から

順番が大事。
①を飛ばして③からやると、急な出費で取り崩す事故が起きます。

私の場合、①に1年かけて、
②③が3ヶ月で終わりました。

焦らない順番、覚えておくと便利です。

※投資にはリスクがあります、判断はご自身で。
```

### サンプル 1-2: 5選

```
家計改善で最初にやる「5選」

①固定費の棚卸し (通信・保険・サブスク)
②生活防衛資金 6ヶ月分の確保
③先取り貯金の自動化
④NISA で月1万円から積立
⑤ボーナス手取り 50%を貯金

①〜③で「守り」、④〜⑤で「攻め」。

私はこの順番で2年かけて
貯金 0円 → 280万円 + NISA 評価額 50万円 に。

派手な手法は何もないです。
順番だけ守れば、誰でも近い結果が出せます。
```

### サンプル 1-3: 5選

```
30代独身が老後資金を準備する「5選」

①ねんきんネットで年金見込み確認
②独身ver の必要額を計算 (約2,800万円)
③NISA を月3万円で開始
④iDeCo を月5,000円で追加
⑤年1回、家計と投資を棚卸し

「2,000万円問題」って既婚前提の数字です。
独身の場合は約2,800万円。

ぼんやり不安を、自分の数字に変えるだけで動けます。

※前提で大きく変動、自分の数字で要試算。
```

### サンプル 1-4: 5選

```
副業を3回挫折した私が4回目で続けるためにやった「5選」

①「1日30分」で時間を限定
②「初収入」を最速で取る (自己アフィなど)
③稼げない時期も「やめない」を優先
④週1で振り返りメモを書く
⑤「楽して」のキーワードに警戒

完璧主義をやめて、
小さく続ける設計に変えただけ。

副業 = 派手 のイメージを捨てるのが大事でした。

詳細はプロフのリンクから ✏
```

## 2. やめたこと型

### 構造

「[私が]やめた○○」「[年齢/期間]でやめたこと」を1行目に。
やめたことの **代わりにどうなったか** を必ず書く (=ポジティブな結果)。

### サンプル 2-1

```
30代でやめて、ラクになった「5つのこと」

①家計簿アプリの毎日入力
②大手キャリアの携帯
③貯蓄型保険
④コンビニATMでの現金引き出し
⑤週末のショッピング習慣

「やめる」ほうが「始める」より、
お金が貯まるスピード速いです。

私は①〜⑤で、年間 約 80万円 の改善。
「節約しよう」じゃなく「やめよう」のほうが、
心理的にも続きました。
```

### サンプル 2-2

```
20代でやめて正解だった「3つのこと」

①「貯金が苦手」と自分に言うこと
②「みんな持ってるから」でクレカを増やすこと
③「もう少し勉強してから」で投資を先延ばし

①: 苦手なんじゃなくて、仕組みがないだけだった
②: クレカ2枚で十分だった
③: 75点で始めたほうが100点を待つより伸びる

20代の自分に言いたい言葉、
30代の今、自分に向けて書いてます。
```

### サンプル 2-3

```
私が副業で「やめた5つ」

①完璧な準備
②派手な情報商材を買うこと
③1日2時間以上やる目標
④「楽して稼げる」言葉を信じること
⑤Twitter で他人の収益と比較すること

これらをやめてから、
副業が3年続いてます。

「やる」より「やめる」が先だった。
特に⑤の「比較」は、心が削られる最大要因でした。
```

### サンプル 2-4

```
家計簿で「やめたこと」3つ

①毎日の入力 (月1の口座確認に変更)
②現金支出の追跡 (キャッシュレス9割化で自動記録)
③ジャンル別の細かい分類 (大枠5つに統合)

これで家計簿時間が
週6時間 → 週15分に。

それでも貯金スピードは変わりませんでした。

「やる量を減らしても結果が変わらない」なら、
減らすのが正解です。
```

### サンプル 2-5

```
30代独身が「やめた」消費5つ

①コンビニ寄り道 (週2回 → 0回)
②大手キャリア (月-5,800円)
③貯蓄型保険 (月-15,000円)
④週刊サブスク雑誌 (月-980円)
⑤ジム年間契約 (3ヶ月行ってなかった、月-7,800円)

合計、月 29,580円。
年で 354,960円。

これを NISA に回したら、
30年後に 約 230万円 の追加資産 (年5%試算)。

やめるだけで、お金は増えます。
```

## 4. List 型を書くときのコツ

### Do

- 各項目に **数字** を入れる (金額・期間・回数)
- 1項目1行で簡潔に
- 「順番」を意識する (重要度・時系列・効果の大きさ)
- 5項目以下を推奨 (7項目以上は読みづらい)
- 各項目に **理由・効果** を1行で添える

### Don't

- 項目数だけ稼ぐ (中身が薄いと信頼を落とす)
- 「絶対やるべき」「必ず買うべき」など断定 (景表法 NG)
- 物販案件で「最安値」「セール中」(Amazon アソシエイト規約 NG)
- 投資・金融商品紹介でリスク注記なし

### 投稿前 セルフチェック

- [ ] 各項目に数字 (金額・回数・期間) がある
- [ ] 1項目1行に収まっている
- [ ] 順番に意味がある (適当に並べてない)
- [ ] 投資・案件含むなら `#PR` がある
- [ ] 500字以内
