# コンテンツ4本柱 (pillars.md)

Threadsの全投稿は4本柱のいずれか1本に紐づく。比率は **3:3:2:2** を基本とし、月次でパフォーマンスを見て微調整する。

---

## 比率設計

| 柱 | 比率 | 週次本数(週14投稿時) | 主な目的 |
|---|---|---|---|
| 1. 共感・ストーリー | 30% | 4本 | フォロー獲得・親近感醸成 |
| 2. 情報提供 | 30% | 4本 | 保存・シェア・専門性印象 |
| 3. 収益化 | 20% | 3本 | プロフ遷移・LINE誘導・案件CV |
| 4. 関係構築 | 20% | 3本 | コメント獲得・アルゴリズム好転 |

> 週28投稿に増える Phase 3 (月7-12) では、各2倍の本数で運用する。

---

## 1. 共感・ストーリー柱 (30%)

### 役割

「この人、私と同じだ」と思わせる投稿。失敗談・気づき・日常の小さな違和感をシェアして人間味を出し、フォロー獲得を狙う。

### 狙う反応 (優先順位)

1. フォロー
2. いいね (共感の意思表示)
3. プロフィール遷移 (もっとこの人を知りたい)
4. (副次) 保存・コメント

### 投稿頻度

週4本 (毎日1本ペース、土日休み or 平日5本)

### 成功例フォーマット

```
[1行目フック: 過去の自分の状態 or 数字付き告白]
[2行目改行]
[3〜10行: ストーリーを短く区切って展開]
[改行]
[気づき・学び 1行]
[改行]
[(任意) 読者への問いかけ 1行]
```

### 想定ペルソナとの相性

- **A (あさひ・投資初心者)**: ◎ 「私もこうだった」が最も刺さる
- **B (ゆうき・副業会社員)**: ○ 失敗談に共感しやすい
- **C (みさき・老後不安独身)**: ◎ 同年代の本音話と相性抜群

### サンプル投稿 (1本)

```
入社2年目の私の貯金、
給料日に残ってた「8,372円」だった。

毎月「今月こそ貯める」って言って、
給料が入った瞬間に欲しい服を買って、
スタバ行って、飲み会行って、
気づいたら通帳が空。

家計簿アプリも3回挫折した。
「自分は意志が弱いんだ」と思ってた。

転機は、給料日に「先取り3万」を別口座に動かす設定をしただけ。
意志力じゃなくて、仕組みに頼った瞬間に、
1年で40万貯まった。

意志が弱いんじゃなくて、
仕組みがなかっただけ。
```

> 文字数: 約235字 (500字以内)

## 2. 情報提供柱 (30%)

### 役割

数値根拠のある情報・整理されたフレームワーク・「知らないと損する」気づきを提供。保存・シェアを狙い、専門性を印象付ける。

### 狙う反応 (優先順位)

1. 保存 (Threads アルゴリズムで最重要シグナルの1つ)
2. シェア (リポスト)
3. プロフィール遷移 (もっと学びたい)
4. (副次) いいね・コメント

### 投稿頻度

週4本

### 成功例フォーマット

```
[1行目フック: 数字 or 問いかけ]
[2行目: 結論先出し]
[空行]
[3〜5項目のリスト or 比較表]
[空行]
[まとめ 1〜2行]
[改行]
[(任意) 「保存しておくと便利」誘導]
```

### 想定ペルソナとの相性

- **A**: ◎ 知識欲が強い、保存される
- **B**: ◎ 副業フレームワーク・節約Tipsで保存
- **C**: ○ 老後資金・資産運用の整理情報

### サンプル投稿 (1本)

```
NISA、結局「成長投資枠」と「つみたて投資枠」どっち?
迷ったときの判断軸 ↓

【つみたて優先で OK な人】
・投資が初めて
・月3万円以下から始めたい
・15年以上保有予定

【成長を活用すべき人】
・年間120万円より多く積みたい
・ETF や個別株も買いたい
・5〜10年で大きく育てたい

迷ったら全額つみたて、慣れたら成長を追加で十分。

※ 投資にはリスクがあります、判断はご自身で。
```

> 文字数: 約225字

## 3. 収益化柱 (20%)

### 役割

高単価案件への自然な紹介。**直接アフィリンクは原則貼らず**、LINE 経由 or プロフ経由で誘導する (Threads 1リンク制約のため)。

### 狙う反応 (優先順位)

1. プロフィール遷移 → LINE 登録
2. 保存 (案件比較記事として)
3. コメント (「私はこれ使ってる」など読者参加)

### 投稿頻度

週3本 (うち1〜2本にアフィリンク or LINE誘導、`#PR` 必須)

### 成功例フォーマット

```
#PR
[1行目フック: 自分の体験 or 数字]
[空行]
[3〜5行: 案件の特徴を「私視点」で紹介]
[空行]
[リスク・注意点 1〜2行]
[空行]
[CTA: 「詳しくは LINE で」 or 「プロフから」]

[ハッシュタグ 3〜5個]
```

### コンプラ最重要ポイント (再掲)

- 冒頭に `#PR`
- 「絶対」「必ず」「儲かる」NG
- 投資系は「個人差」「リスク」を必ず明記
- LINE 内配信に Amazon リンクは貼らない (規約NG)

### 想定ペルソナとの相性

- **A**: ◎ NISA・証券口座への自然な誘導
- **B**: ◎ FX口座・クレカ自己アフィへの誘導
- **C**: ○ 投資信託サブスク・FP相談へ

### サンプル投稿 (1本)

```
#PR

NISA を始めるとき、私は楽天証券から始めました。

理由は3つ。
・楽天ポイントで投資できる (心理的ハードル低)
・アプリが初心者にも分かりやすい
・楽天市場との連携で家計と結びつけやすい

ただ、SBI 証券のほうが手数料・取扱商品で
有利な部分もあります。
私の場合は「使い慣れたサービスから」を優先しました。

迷っている方は、私のプロフから
「証券口座 比較チェックリスト」配布してます ✏

※投資にはリスクがあります、判断はご自身で。

#NISA #投資初心者 #yuruFIRE
```

> 文字数: 約290字

## 4. 関係構築柱 (20%)

### 役割

質問投稿・読者コメントへの返信引用・対話型投稿で、Threads 特有の **会話文化** を活用する。アルゴリズム的にもコメント数は重要シグナル。

### 狙う反応 (優先順位)

1. コメント (最優先)
2. リポスト・引用
3. フォロー (会話の人として認知)

### 投稿頻度

週3本

### 成功例フォーマット

#### 質問投稿型

```
[1行目: シンプルな質問]
[2〜3行: 自分の答えを先に開示]
[改行]
[「あなたはどう?」]
```

#### 引用返信型

```
[読者コメント引用 (Threads機能)]
[改行]
[しほの返信 + 一般化された学び]
```

### 想定ペルソナとの相性

全ペルソナ汎用。コメントしてくれる人は熱量高めの読者なので、すべてのペルソナに刺さる設計を。

### サンプル投稿 (2本)

#### 質問投稿型

```
「節約のために最初にやめたこと」
何でしたか?

私は「コンビニATMで現金を下ろすこと」でした。
手数料 220円 × 月3回 = 月660円。
1年で7,920円。
ATMネットで使えるネット銀行に変えるだけで消えた支出。

あなたが最初にやめたこと、教えてください ☕
```

> 文字数: 約170字

#### 引用返信型

```
> @reader_aさんのコメント:
> 「私は飲み会を月1回に減らしました!」

すごい、月1ペースって意志ありますね。
私も飲み会代って気づくと月3万行くタイプで、
「2軒目だけやめる」ルール作ったらだいぶ変わりました。

「全部やめる」より「1段階下げる」のほうが、
私の場合は続きやすいです。
```

> 文字数: 約160字

## 6. 月次 比率レビュー

毎月末に以下を確認:

- 4本柱それぞれのインプレ平均・保存数・コメント数
- 「収益化」柱の CV 貢献度
- 「関係構築」柱からの新規フォロワー流入
- 来月の比率調整 (±5% まで、変えすぎは混乱)

> 安定して伸びている柱があれば、そこを **35%まで** 増やしても OK。
> ただし「収益化」柱を 30%以上にすると売り込み感が強くなり、フォロー解除を招きやすい。
