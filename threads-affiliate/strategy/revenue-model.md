# 収益モデル設計 (revenue-model.md)

3ヶ月で月30万円、12ヶ月で月100万円のアフィリエイト収益到達を逆算で設計する。

---

## 1. 収益方程式

```
月収 = フォロワー数 × 投稿到達率 × クリック率(CTR) × 登録CVR × 購入CVR × 単価 × 承認率
```

ただし Threads → LINE → ASP の3段階を経るため、実務的には次のように分解する:

```
月収 = (Threads月間インプレッション × プロフィール遷移率 × LINE登録率)  ← 月間LINE登録数 N
       × LINE案件購入率 × 単価 × 承認率
```

### 各 KPI の業界ベンチマーク (2026年仮置き)

| 指標 | 弱め | 標準 | 強め | 注釈 |
|---|---|---|---|---|
| Threads 1投稿あたりインプレ | 500 | 3,000 | 15,000 | フォロワー数の30〜200%が目安 |
| 投稿→プロフ遷移率 | 0.5% | 1.5% | 3% | フック投稿で 3% 超もあり得る |
| プロフ→LINE登録率 | 5% | 15% | 30% | 特典PDFの強さで変動 |
| LINEステップ→案件クリック率 | 10% | 25% | 40% | リスト鮮度で変動 |
| 案件クリック→申込CVR | 2% | 8% | 20% | 案件・LP の質に依存 |
| ASP 承認率 | 50% | 70% | 90% | 自己アフィ・規約違反で大幅低下 |
| 高単価案件単価 | 5,000 | 15,000 | 30,000 | FX口座開設・クレカ・転職など |

> **注**: 2026年5月時点の市場相場感を仮置き。実数はユーザーが ASP 管理画面 / Threads Insights で確認・更新する。

---

## 2. 月30万円ルート (3ヶ月目標)

### 設計思想

「**高単価1案件 × 月10〜20件**」に集中。LINE リストはまだ薄い (500〜1,500人) ので、Threads から直接 LP に飛ばすパターンと LINE 経由の両方を併用する。

### 想定案件

- **FX 口座開設** (例: DMM FX、外為どっとコム、みんなのFX 等)
  - 単価レンジ: 1.5万円 〜 3万円/件 (取引条件達成ベース)
  - 承認率: 50〜70% (取引未達で否認発生)

### 逆算式

| 項目 | 値 | 計算根拠 |
|---|---|---|
| 月収目標 | 300,000円 | |
| 単価 (承認率込み実効単価) | 15,000円 | 単価22,500円 × 承認率67% |
| 必要承認件数 | 20件 | 300,000 ÷ 15,000 |
| 必要発生件数 | 30件 | 20件 ÷ 承認率67% |
| 必要案件クリック数 | 375 | 30件 ÷ 申込CVR 8% |
| 必要 LINE 登録 (3ヶ月累計) | 1,500人 | 375 ÷ クリック率25% |
| 必要 Threads インプレ (月間) | 500,000 | 1,500人/3ヶ月 ÷ プロフ遷移1.5% ÷ 登録率15% |
| 必要 1日あたり投稿数 × インプレ | 16,667/日 | 500,000 ÷ 30日 |
| → 1日2投稿 × 平均インプレ | 8,000+8,000 | 投稿数を増やすか質を上げるかの選択 |

### 必要アクション

- フォロワー 1,000 → 5,000 (3ヶ月で 5倍)
- 週投稿数 14 → 21 (毎日2投稿ペース、X からの転用半分以上)
- LINE 登録 月50人 → 月300人 (特典PDF + プロフ導線最適化)
- 高単価CV: 月2件 → 月15〜20件

## 3. 月100万円ルート (12ヶ月目標)

### 設計思想

「**単価分散 × LINE 3,000人ベース**」で複数案件を並走。LINE 内ステップ配信 (5〜7通) で信頼形成 → 案件をローテーション露出。

### 想定案件ポートフォリオ

| カテゴリ | 想定単価 | 想定月CV | 月収貢献 |
|---|---|---|---|
| FX口座開設 (主軸) | 15,000円 | 25件 | 375,000円 |
| ネット証券口座 | 10,000円 | 20件 | 200,000円 |
| クレカ | 8,000円 | 15件 | 120,000円 |
| 投資/会計サブスク | 5,000円 | 20件 | 100,000円 |
| 情報商材 (note自社含む) | 3,500円 | 50件 | 175,000円 |
| その他 (転職・スクール等) | 20,000円 | 1〜2件 | 30,000円 |
| **合計** | — | **約130件/月** | **1,000,000円** |

### 逆算式

| 項目 | 値 | 計算根拠 |
|---|---|---|
| 月収目標 | 1,000,000円 | |
| 必要承認件数 | 約130件 | ポートフォリオ加重平均 |
| 必要発生件数 | 約185件 | 承認率70% |
| 必要案件クリック数 | 2,300 | 185 ÷ 8% |
| LINE リスト鮮度 (アクティブ率40%想定) | 3,000人中 1,200人がアクティブ | |
| アクティブ × 月クリック率 | 1,200 × 1.9 クリック/月 = 2,300 | OK |
| 必要 Threads → LINE 月間流入 | 約300人/月 | リスト維持 + 純増分 |
| 必要 Threads インプレ (月間) | 1,200,000+ | プロフ遷移1.5%, 登録15% |

### 必要アクション

- フォロワー 5,000 → 20,000 (Q3-Q4で 4倍)
- 週投稿数 21 → 28 (毎日4投稿ペース、転用 + オリジナル混合)
- LINE 登録 月300人 → 月1,000人
- ステップ配信を **2軸 (投資ファンネル / 副業ファンネル) に分岐**
- 自社商品 (note) を月 50件売って単価分散の柱の1つに

## 4. タイムライン

### 月1〜3: 土台構築フェーズ

- **目標月収**: 月1=1万 → 月2=5万 → 月3=10〜30万
- **重点**:
  - プロフィール完成、固定投稿、LINE特典PDF (3種)
  - 共感投稿で 1,000 フォロワー獲得
  - X / note からの転用 70%、オリジナル 30%
  - 1案件 (FX口座) に絞って LP・LINE ステップを完成
- **ボトルネック**: フォロワー獲得・LINE登録特典の魅力度

### 月4〜6: 30万円到達フェーズ

- **目標月収**: 月4=15万 → 月5=22万 → 月6=30万
- **重点**:
  - フォロワー 5,000 達成、週21投稿の量産体制
  - LINE 登録 月300人 / リスト1,500人
  - 高単価1案件で 月15〜20件の安定 CV
  - A/B テスト (フック型・LP コピー) を週次で回す
- **ボトルネック**: 案件 CVR、LINE ステップの最終 CTA

### 月7〜12: 100万円到達フェーズ

- **目標月収**: 月7=40万 → 月9=60万 → 月12=100万
- **重点**:
  - フォロワー 20,000、月間インプレ 100万+
  - LINE リスト 3,000人、ファネル分岐 (投資/副業)
  - 案件ポートフォリオ化 (5〜7案件並走)
  - 自社商品 (note) を昇華、第3チャネル (Instagram or YouTube Shorts) 検証
- **ボトルネック**: 案件依存リスク、LINE 解除率、自社商品の制作工数

## 5. ストレステスト (悲観シナリオ)

下記のように KPI が悪化した場合の月収:

| シナリオ | プロフ遷移 | LINE登録率 | 申込CVR | 月収 (月6時点) |
|---|---|---|---|---|
| 標準 | 1.5% | 15% | 8% | 30万円 |
| -25% | 1.1% | 11% | 6% | 約12万円 |
| -50% | 0.75% | 7.5% | 4% | 約4万円 |

**対策**: 月3時点で標準値の70%を割っている指標があれば、**フック改善 / 特典PDF差替 / 案件変更** を検討する。

---

## 6. 表現上のコンプラ注意

本ドキュメント内の数値はすべて **目標** であり、視聴者・読者向けの投稿には「絶対」「必ず」「○ヶ月で稼げる」等の断定表現を使わない。

投稿で収益を語る際は次のテンプレを使う:

> ❌ 「Threadsで月30万稼げます」
> ⭕ 「私の場合は3ヶ月で月30万を目指して、こんな設計をしてみました」(=自分の体験 / 試行)

詳細は `compliance-checklist.md` 参照。
