# コンプライアンス チェックリスト (compliance-checklist.md)

Threads × 高単価アフィリエイト (FX・証券・クレカ・転職等) で **絶対に守る** べき法令・規約。違反は措置命令・案件停止・アカウント BAN を招く。

> 構造は本リポジトリ既存の `docs/compliance.md` (占い動画用) を踏襲し、**金融特化のNG表現** を上乗せしている。

---

## 1. ステマ規制 (景品表示法 不当表示告示 第20号、2023.10〜)

### 要件

事業者から提供を受けた広告は、それが広告であることを **一般消費者が容易に判別できる形で明示** する必要がある。判別不可能 = ステマ = 景表法違反 (措置命令対象)。

### 本プロジェクトでの実装

- アフィリエイトリンクを含む投稿の **冒頭** に必ず以下のいずれかを記載:
  - `#PR`
  - `#広告`
  - `#プロモーション`
  - 「広告を含みます」
- LINE 配信内でアフィリンクを送る場合も同様
- ハッシュタグの末尾ではなく、**冒頭または最初のハッシュタグ群** に置くこと
- LP / Linktree の該当ボタン横にも「広告」明記

### NG例 / OK例

| パターン | 表記位置 | 判定 |
|---|---|---|
| 冒頭に `#PR`、本文末尾にアフィリンク | OK | ⭕ |
| 本文末尾に小さく「※PR」 | NG (冒頭ではない) | ❌ |
| 「個人的に最高の口座!」+ アフィリンク (PR表記なし) | NG | ❌ ステマ |

### 自動チェック (将来 compliance_check.py 実装)

```python
PR_TAGS = ["#PR", "#広告", "#プロモーション", "広告を含みます", "[PR]"]
if has_affiliate_link(post) and not any(tag in post[:200] for tag in PR_TAGS):
    raise ComplianceError("PR表記が冒頭200文字に存在しません")
```

## 2. 景品表示法 (優良誤認・有利誤認)

### NG表現リスト (Threads投稿・LINE配信・LP すべて禁止)

#### 断定・確実性

- 「絶対」「必ず」「100%」「確実に」「間違いなく」
- 「絶対に儲かる」「必ず勝てる」 → 「私の場合は○○できた」「人によって結果は異なります」に置換
- 「失敗しない」「リスクゼロ」 → 「想定リスクは○○です」に明示

#### 効能・効果の保証 (金融文脈)

- 「月10万円稼げます」 → 「私は月10万円のときがありました」(自己体験+断定回避)
- 「資産が○倍になる」 → 「私は○年で○倍になった (リスクは○○)」
- 「老後の不安が消える」 → 「老後資金の見通しが立つきっかけになるかも」

#### 比較優位

- 「業界No.1」「最強の証券会社」「日本一」
- 数値根拠のない「満足度95%」「利用者数1位」
- → 客観データ (公的機関 / 案件公式) を引用、または「私が比較した中では」と限定

### 緩衝句テンプレ

投資・副業系 投稿の末尾には以下のいずれかを自然に挿入:

- 「※投資はリスクを伴います。ご自身の判断で」
- 「結果には個人差があります」
- 「最終的な判断はあなた自身で」
- 「将来の運用成果を保証するものではありません」

### 自動チェック対象NG語 (regex)

```
(絶対|必ず|100%|確実に|間違いなく)(に|で)?(儲か|稼げ|当た|成功)
(業界|日本|世界)(no\.?1|ナンバーワン|一)
(元本保証|ノーリスク|リスクゼロ)
(満足度|利用者数)\s?\d{1,3}\s?[%％]
```

## 3. 金融商品取引法 (金商法)

### 適用対象

FX・証券・暗号資産・投資信託など「金融商品」を紹介する場合。本プロジェクトでは **最重要**。

### NG (38条 — 断定的判断の提供 禁止)

- 「この銘柄は必ず上がる」
- 「絶対に儲かる FX 業者」
- 「○ヶ月で○万円稼げる手法」
- 「この口座を開けば成功する」

### NG (37条の3 — 重要事項の不告知)

- リスク説明を省く (例:「FX で月10万!」だけで損失リスクに触れない)
- 元本保証されないことを明示しない

### OK 表現 (代替テンプレ)

| ❌ NG | ⭕ OK |
|---|---|
| FXで絶対稼げます | 私は FX 取引で○○の経験があります (リスクは○○です) |
| 必ず上がる銘柄 | 私が注目している銘柄 (投資判断はご自身で) |
| 元本保証 | 元本割れの可能性があります |
| 月50万稼げた | 月50万になったことがあります (年間平均は○万) |

### 投資系投稿 必須記載事項

- リスク注記: 「投資にはリスクがあります」「元本保証はありません」
- 自己判断喚起: 「投資判断はご自身で」
- (案件によっては) 「金融商品取引業者○○ の広告です」(ASP指定の場合)

### 暗号資産特有

- 「価格が必ず上がる」「億り人になれる」は厳禁
- 詐欺的なプロジェクトの紹介は絶対NG (案件選定段階で除外)

## 4. 薬機法 (健康・美容案件を扱う場合)

本プロジェクトの主軸は金融だが、サブで美容・健康サブスクを扱う場合のため記載。

### NG

- 「○日で痩せる」「シミが消える」「肌がきれいになる」
- 「不眠が治る」「うつが軽くなる」「免疫力アップ」
- 「○○を治す」「○○の効果がある」

### OK 表現

- 「私は使ってみてこう感じました」(個人感想)
- 「成分表ではこう書かれています」(客観事実)
- 「医師の意見では○○とされています」(出典明示)

### 安全策

- 健康・美容案件は当面 **扱わない** (金融特化を維持)
- 扱う場合は薬機法に詳しい人にチェックしてもらう

---

## 5. 特定商取引法・個人情報保護法

- 視聴者の生年月日・住所などの **個人情報を Threads 上で募集しない**
- LINE 公式での登録時もメールアドレス・氏名のみ (それ以上は ASP 側へ誘導)
- 自社商品 (note 有料記事) を販売する場合、特商法表記が必要 (note は標準で対応)

---

## 6. 未成年保護

- 18歳未満を主たる対象とした金融サービス誘導は禁止
- 投稿に「学生でも」と書く場合は、20歳以上の学生を想定し、その旨を明記
- LINE 登録時に年齢確認はしないが、配信内に「18歳以上推奨」を明記

## 7. ASP 別 個別規約サマリ

### A8.net

- 自己アフィ (セルフバック) 不可案件あり (案件詳細を要確認)
- リスティング広告 (Google広告など) 不可案件あり
- ブランド名の不適切使用禁止 (案件名で検索 → 過剰な煽り表現NG)
- 比較・順位付けNGの案件あり (FX・証券に多い)
- 規約は変動するため `asp/product-list.md` 更新時に再確認

### もしもアフィリエイト (Amazon・楽天・物販)

- Amazon アソシエイトは LINE 内配信でのリンク貼り付けが NG (Amazon は **公開ウェブサイト** のみ許可)
- 楽天アフィリエイトは LINE OK (要規約確認)
- 「ステマ」とみなされる表現は厳格にチェック

### afb (アフィb)

- 美容・健康系の薬機法チェックが厳しい
- 案件によっては「投稿前審査」あり (これに違反すると報酬否認)

### アクセストレード

- 金融案件 (FX・証券) の規約が比較的厳しい
- 「絶対儲かる」系の表現は即時 NG 通告

### Amazon アソシエイト

- LINE 内配信NG (公開ウェブサイト=Threads / note / X はOK)
- 価格の明記禁止 (常に変動するため)
- 「最安値」「セール中」も NG (日々変わるため)
- 規約違反でアカウント停止 → 全アフィリエイト履歴消滅 のリスクあり

## 8. Threads プラットフォーム規約

- 外部リンク連投はシャドウバンの可能性 (1投稿1リンクが安全)
- 自動投稿ツールの過剰使用は規約違反 (1日100投稿などはNG)
- 他人のコンテンツの無断転載 NG (X からの転用も自分の発言のみ)
- スパム的なフォロー・アンフォローは凍結対象

## 9. 投稿前 最終チェックリスト (1投稿ごと)

### 全投稿共通

- [ ] 「絶対」「必ず」「100%」「確実に」が含まれていない
- [ ] 「業界No.1」「最強」など根拠のない最上級表現がない
- [ ] 投稿は500字以内

### アフィリンク含む投稿

- [ ] 冒頭200文字以内に `#PR` または「広告」表記がある
- [ ] アフィリンクは1本まで
- [ ] 末尾に緩衝句 (「投資はリスクを伴います」「個人差があります」等) がある
- [ ] 案件規約 (A8 / もしも 等) に違反する表現・タグがない

### 投資系 (FX・証券・暗号資産)

- [ ] 断定的判断の提供 (38条) に該当する表現がない
- [ ] リスク説明が含まれている (「元本割れの可能性」等)
- [ ] 「必ず儲かる」「絶対上がる」が **どこにもない** (本文・コメント・LP)

### 健康・美容系 (扱う場合)

- [ ] 効果効能の断定がない
- [ ] 治療・治癒を匂わせる表現がない

### 副業系

- [ ] 「楽して稼げる」「誰でも簡単に」がない
- [ ] 必要な労力・時間・元手を明示

## 10. 違反疑義時の対応

1. 該当投稿を **即座に削除 or 編集** する
2. ASP 担当者に連絡し、報酬否認可能性を確認
3. 同種パターンを過去投稿から検索 (`grep`) し、修正
4. `compliance-checklist.md` に該当事例を追記し、再発防止
5. (重大時) 一定期間 アフィリ系投稿を停止 + 弁護士・税理士に相談
