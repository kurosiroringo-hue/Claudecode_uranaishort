# ファネル設計 (funnel-design.md)

Threads → LINE → 高単価案件の3段階ファネル。各段階に明確な役割・KPI・メッセージ例・ボトルネック診断を持たせる。

---

## ファネル全体像

```
[TOFU] Threads 単発投稿 (共感・気づき・情報)
   ↓ プロフィール遷移率: 1.5% (標準)
[MOFU] プロフィール / 固定投稿 / Linktree → LINE 公式登録
   ↓ プロフ→LINE 登録率: 15% (標準)
[BOFU] LINE 5〜7通ステップ配信 → 高単価案件CTA
   ↓ ステップ完走 × 案件 CV: 8% (標準)
=> 月間 LINE 登録 N 人 → 約 N × 0.08 件の CV
```

各段階に直アフィリエイトリンクを置きすぎない。**TOFU は売らない、MOFU は登録だけ、BOFU で売る** が原則。

---

## 1. TOFU: Threads 単発投稿 (認知獲得)

### 役割

- 通りすがりのユーザーに「この人の発信、続きを見たい」と思わせる
- 直接アフィリンクは置かない (1投稿1リンクの Threads 文化に反する + ファネルが薄くなる)
- 「保存される」「コメントされる」「プロフ遷移される」の3つを同時に狙う

### 投稿の役割分担 (4本柱)

| 柱 | TOFU での役割 |
|---|---|
| 共感ストーリー (30%) | フォロー獲得・親近感 |
| 情報提供 (30%) | 保存・シェア・専門性印象 |
| 収益化 (20%) | プロフ遷移誘導 (案件は LINE 内で出す) |
| 関係構築 (20%) | コメント獲得・アルゴリズム好転 |

### KPI

| 指標 | 月1-3 目標 | 月4-6 目標 | 月7-12 目標 |
|---|---|---|---|
| 1投稿平均インプレ | 2,000 | 8,000 | 30,000 |
| 1投稿平均いいね | 30 | 150 | 600 |
| 1投稿平均保存 | 5 | 30 | 150 |
| 1投稿平均コメント | 2 | 10 | 40 |
| プロフィール遷移率 | 0.8% | 1.5% | 2.5% |

### TOFU メッセージ例 (柱別 1サンプル)

#### 共感ストーリー柱

```
入社3年目で貯金ゼロだった私が、
最初にやったのは「家計簿アプリ」じゃなかった。

やったのは、給料日に「先取り3万円」を別口座に動かすこと。
それだけ。

家計簿は3回挫折してたから、もう自分で管理する選択を捨てた。
今は月10万を勝手に貯金口座に移してくれてる。

意志力に頼ると続かない。
仕組みで貯まる方を選んだ。
```

#### 情報提供柱

```
NISA、結局「成長投資枠」と「つみたて投資枠」どっち?
迷ったときの判断軸 ↓

【つみたて優先で OK な人】
・投資が初めて
・月3万円以下から始めたい
・15年以上保有予定

【成長を活用すべき人】
・年間120万円より多く積みたい
・ETF や個別株も買いたい
・5〜10年で大きく育てたい

迷ったら全額つみたて、慣れたら成長を追加で十分。
```

### TOFU ボトルネック診断

| 症状 | 仮説 | 打ち手 |
|---|---|---|
| インプレ500未満が続く | フックが弱い / シャドウバン気味 | 1行目改善 + 投稿時間変更 + 24h ハッシュタグ削減 |
| インプレ多いが いいね少ない (1%未満) | 内容と読者期待のミスマッチ | ペルソナ A/B/C のどれに刺すかを明確化 |
| プロフ遷移 0.5%未満 | 「もっと知りたい」誘発がない | 投稿末尾に「プロフに○○置いてます」を週1で追加 |
| コメント1件もつかない | 読者参加余地がない | 質問を1つだけ書く / 「あなたはどう?」型を週2回 |

## 2. MOFU: プロフィール → LINE 登録

### 役割

- TOFU で「気になる」と思った人を **LINE 公式に確実に着地** させる
- 案件は売らない。ここでも売らない。**「特典を受け取りに来た」状態** を作る

### 構成要素

#### プロフィール (Threads 自己紹介)

```
yuru-FIRE目指す経理OL / 簿記2級
✏ お金の不安を「仕組み」で解く発信
🔗 NISA 1ヶ月目チェックリスト 配布中 ↓
   linktr.ee/your_handle
```

> **ポイント**: 1行目で属性、2行目で価値、3行目で特典 → リンク。
> 絵文字は1〜2個まで (Threads では使いすぎ逆効果)。

#### 固定投稿 (1〜2本)

- 自己紹介 + 過去のベスト体験談 + LINE 特典
- 月1で更新 (パフォーマンスを見て差し替え)

#### Linktree (or 独自リンクページ)

- LINE公式登録ボタン (一番上、最大文字数)
- note 自社記事 (2番目)
- X / Instagram など他チャネル (3番目以下)
- アフィ直リンクは **最下段に1つだけ** (Phase 3 以降)

#### LINE 特典 PDF (3種推奨)

1. **「NISA 1ヶ月目チェックリスト」**: ペルソナA向け
2. **「副業 月3万への手順書」**: ペルソナB向け
3. **「30代独身のための家計診断テンプレ」**: ペルソナC向け

特典は **A4 5〜10ページ** で十分。Canva で1日で作れる粒度。
PDF 内に LINE 内で配信する案件への自然な布石を入れる (例:「次回、おすすめ証券会社を配信します」)。

### KPI

| 指標 | 月1-3 目標 | 月4-6 目標 | 月7-12 目標 |
|---|---|---|---|
| プロフ遷移→Linktreeクリック | 60% | 70% | 75% |
| Linktree→LINE登録ボタン押下 | 30% | 40% | 45% |
| LINE登録CVR (プロフ遷移ベース) | 10% | 15% | 20% |
| 月間 LINE 新規登録 | 50人 | 300人 | 1,000人 |

### MOFU ボトルネック診断

| 症状 | 仮説 | 打ち手 |
|---|---|---|
| プロフ遷移は多いが Linktree クリック少ない | プロフ文の特典訴求が弱い | プロフ3行目を「特典名 + 数字」に書き換え |
| Linktree クリックは多いが LINE 登録少ない | 特典の魅力が読み手とミスマッチ | 特典 PDF を3種にし、ペルソナ別に提示 |
| LINE 登録後すぐに解除される | 配信内容と特典のズレ | 登録直後の挨拶配信を「期待値調整」に書き換え |

## 3. BOFU: LINE ステップ配信 → 高単価案件 CV

### 役割

- 信頼形成 → 教育 → 自然な提案 → CV
- **5〜7通の自動ステップ** で心理的に階段を上らせる
- 1ステップ = 1テーマ。詰め込みは禁物

### 5通版テンプレ (シンプル / Phase1-2 用)

| # | 配信タイミング | テーマ | CTA |
|---|---|---|---|
| 1 | 登録直後 | お礼 + 特典 PDF 配布 + 自己紹介 | なし (信頼形成のみ) |
| 2 | 翌日 | 私の失敗ストーリー (家計崩壊→立て直し) | なし (共感のみ) |
| 3 | 3日後 | NISA / 投資の最初の1歩 教育コンテンツ | 案件への布石 (まだ売らない) |
| 4 | 5日後 | 「私が最初に開いた口座はこれ」案件提案 (#PR) | アフィリンク (案件A) |
| 5 | 7日後 | フォローメッセ + 質問募集 | LINE 1on1 質問誘導 |

### 7通版テンプレ (Phase 3 以降、高単価特化)

| # | 配信タイミング | テーマ | CTA |
|---|---|---|---|
| 1 | 登録直後 | お礼 + 特典 + 「7日間で○○できるよう設計しました」 | 期待値調整 |
| 2 | 翌日 | 失敗ストーリー (詳細版) | なし |
| 3 | 3日後 | 教育①: 投資の基本3原則 | なし |
| 4 | 4日後 | 教育②: 口座選びの判断軸 | なし (CTA はリンクなし) |
| 5 | 5日後 | 案件A 紹介 (FX) + リスク説明 (#PR) | アフィリンク (案件A) |
| 6 | 6日後 | 案件B 紹介 (証券) (#PR) | アフィリンク (案件B) |
| 7 | 7日後 | まとめ + 自社商品 (note) 提案 | note リンク |

### LINE 配信 メッセージ例 (#3 教育コンテンツ)

```
こんばんは、しほです。

3日前にお会いしたばかりですが、
今日はちょっと真面目な話を。

NISAって聞いて、こんな印象ないですか?
・難しそう
・元本割れが怖い
・どこで開けばいいかわからない

私も2年前まで同じでした。
今日はその「最初の不安」を一個ずつ
分解していきますね。

(続きは次のメッセージで)
```

> **ポイント**:
> - 1メッセージは LINE のスクロール 1〜2画面に収まる長さ
> - 改行を多用、絵文字は最小限
> - 「次のメッセージで」で続きを期待させ、開封率を上げる

### KPI

| 指標 | 月1-3 目標 | 月4-6 目標 | 月7-12 目標 |
|---|---|---|---|
| LINE ステップ完走率 | 40% | 55% | 65% |
| ステップ内案件クリック率 | 15% | 25% | 35% |
| 案件クリック→CV (申込) | 5% | 8% | 12% |
| LINE 解除率 (月) | 8% | 5% | 3% |
| 月間 高単価CV | 2件 | 15件 | 60件 |

### BOFU ボトルネック診断

| 症状 | 仮説 | 打ち手 |
|---|---|---|
| ステップ完走率 30%未満 | 配信頻度が高すぎる / 内容が冗長 | 7通→5通に圧縮、1メッセージ300字以内に |
| 案件クリック率 10%未満 | 案件提案が唐突 (前段の教育不足) | 教育#3-4 を厚くし、案件説明を「失敗回避」軸に |
| クリック→CV 3%未満 | LP / ASP 案件側の問題 | 案件差し替え (EPC ベース) または LP 改善 |
| 解除率 10%超 | 配信内容と期待のズレ / 売り込み感強すぎ | 案件配信を 3〜5通目に分散、無料コンテンツを増やす |

## 4. ファネル全体の月次レビュー観点

毎月末に以下を確認:

```
TOFU 月間インプレ ÷ プロフ遷移 = TOFU効率
プロフ遷移 ÷ LINE登録 = MOFU効率
LINE登録 ÷ 案件CV = BOFU効率
LINE登録 ÷ 解除 = リスト鮮度
```

> **判断基準**: 標準値の70%を割っている指標があれば、その層を最優先で改善する。
> 例: TOFU 効率 0.8% (標準 1.5%) なら、まず TOFU (フック・投稿頻度) を改善し MOFU・BOFU には触らない。
