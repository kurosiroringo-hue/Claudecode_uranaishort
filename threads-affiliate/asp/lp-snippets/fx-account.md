# LP 雛形: FX 口座開設 カテゴリ

LINE 内ステップ配信または独自LP で配信するミニLP原稿。
**主軸案件** (3ヶ月で月30万円ルートの主砲) のため、最も丁寧に書く。

> ⚠️ 金商法 38条 (断定的判断の提供禁止) を最優先で遵守。
> ⚠️ `compliance-checklist.md` の投資系チェックリスト全項目を通すこと。

---

## 1. ヘッドライン (3案を A/B テスト)

```
A: 「投資が初めてだった私が、FX口座を選んだ3つの理由」
B: 「FX = 怖い、と思ってた私の最初の口座開設レポ」
C: 「自己アフィで“1万円”、初収入を作った日の話」
```

> 「絶対稼げる」「必ず勝てる」系は使わない。**自分の体験ベース** で開く。

## 2. 共感パート (約 200字)

```
こんばんは、しほです。

「FX」と聞いて、最初に思い浮かぶイメージって何ですか?

私は2年前まで、こんなイメージでした。
・大損する人が多そう
・難しい用語ばかり
・専業トレーダー向け

このイメージのまま3年スルーしてました。

でもある日、副業の初収入を作りたくて
「自己アフィ可能な案件」を探したら、
FX口座開設で 1万円キャッシュバック という案件を見つけて。

そこから少しずつ、知識を入れていきました。
```

## 3. 解決パート (約 300字)

```
私が FX口座開設で一番不安だったのは
「開設したら、すぐに取引しないといけないの?」でした。

結論、 不要 です。

口座を開いても、自分が動かなければ何も起きません。
私の場合、開設して1ヶ月、まったくログインしませんでした。

そのうえで、自己アフィのキャッシュバック条件を満たすために
最小単位 (1,000通貨 〜 1万通貨) で 数回取引してから、
半年放置しています。

私が口座を開いた基準はこの3つ:

①最小取引単位が小さい (=損が小さい)
②スプレッドが業界水準より狭い (=コスト低)
③大手で信頼性がある (=出金トラブル少)

これに合った FX 業者を選んで、
慎重にスタートしました。
```

## 6. 注意書き (リスク・断定回避、約 100字)

```
※ 以下の点を必ずご確認のうえ、ご自身の判断でご検討ください。

・FX は元本割れの可能性がある金融商品です
・レバレッジを高くすると、入金額以上の損失が出る場合があります
・「絶対勝てる手法」は存在しません
・税金 (申告分離課税 20.315%) の発生に注意

しほの体験談はあくまで一例で、結果には個人差があります。
不安な方は、まずデモ口座から始めるのがおすすめです。
```

## 7. 全体構成サマリ

| パート | 字数 | 役割 |
|---|---|---|
| ヘッドライン | 30〜40字 | 興味喚起 |
| 共感 | 約200字 | 「自分も同じ」と思わせる |
| 解決 | 約300字 | 「こうすれば良いんだ」と納得させる |
| 証拠 | 約200字 | 数字で信頼を補強 |
| CTA | 約100字 | リンクへの自然な誘導 |
| 注意書き | 約100字 | コンプラ + 信頼形成 |
| **合計** | 約 900〜1,000字 | LINE 配信1通分に最適 |

## 8. A/B テスト 仮説 (4週でローテ)

| 週 | 仮説 | 変更箇所 |
|---|---|---|
| 1 | ベースライン | 上記そのまま |
| 2 | 共感の冒頭を質問型に | 「FX に最初に持ったイメージは?」 |
| 3 | 解決パートに「3つの不安 → 3つの回答」型を追加 | 構造変更 |
| 4 | CTA の前に「私の友人もこの順番で始めた」追加 | 社会的証明 |

各週の CVR (= 配信開封 → アフィクリック → 申込) を比較し、最強パターンを採用。

## 9. NG 表現チェック (送信前最終)

- [ ] 「絶対」「必ず」「100%」「確実」が含まれない
- [ ] 「絶対勝てる」「必ず儲かる」が含まれない
- [ ] 「元本保証」「ノーリスク」が含まれない
- [ ] 「業界No.1」「最強」が含まれない
- [ ] 末尾に「個人差」「リスク」明記
- [ ] アフィリンク前後に `#PR` または「広告」表示
- [ ] 案件規約 (キャッシュバック金額・条件) が最新か
- [ ] 18歳未満を主たる対象としていない

---

## 10. 配信タイミング (LINE ステップ#5)

- ステップ#1〜4 で「教育」を完了させた後に投入
- 唐突に売り込まず、「私の体験」として静かに紹介
- 配信後 24時間以内のクリック率が最重要 KPI
- クリック率 25%超なら成功、15%未満なら ヘッドライン or 共感パートを次回テスト
