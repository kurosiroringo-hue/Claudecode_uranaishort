# LP 雛形: スキル系スクール カテゴリ

簿記・FP・プログラミング・英会話などの学習サービス。
しほさんの本人キャラ (簿記2級保有) と相性が良く、信頼度の高い案件。

> 景表法 遵守。「○ヶ月で○万稼げる」「絶対合格」NG。
> 個人差・労力を必ず明記。

---

## 1. ヘッドライン (3案)

```
A: 「簿記2級を取って、私の働き方が変わった話」
B: 「独学で挫折した私が、オンライン講座で完走できた理由」
C: 「『何を学ぶか』より『続けられるか』が9割でした」
```

---

## 2. 共感パート (約 200字)

```
こんばんは、しほです。

「何かスキルをつけたいけど、何から始めればいいか分からない」

これ、20代の頃の私です。

英会話・プログラミング・WEBデザイン…
有名どころを片っ端から試して、
すべて2週間で挫折しました。

理由は単純で、
「目的」が決まってなかったから。

「キャリアアップ」は曖昧すぎて、
やる気が続きません。

私が続けられた最初のスキルは、
「目的が具体的」な簿記でした。
```

---

## 3. 解決パート (約 300字)

```
結論: スキル選びは「目的の解像度」で決まります。

【続きやすい目的の例】
・経理に異動したい → 簿記2級
・副業の確定申告を自分でやりたい → 簿記3級 + 確定申告講座
・FP相談を有料化したい → FP3級・2級
・転職時に時給を上げたい → ITパスポート + Excel上級

私の場合、本業 (経理) と直結する簿記を選びました。
3ヶ月で2級合格、独学では何度も挫折してたのが、
オンライン講座 (動画 + 添削) に切り替えて完走。

学習コストは:
・受講料 約 25,000円
・学習時間 平日30分 + 土日2時間 × 12週

現在、簿記2級を取得したことで:
・本業での社内評価UP
・副業 (会計サブスク紹介) の信頼性UP
・noteで簿記関連記事を有料販売
の3つが繋がっています。
```

## 4. 証拠パート (約 150字)

```
私が使ったオンライン講座の体験:

【簿記2級 オンライン講座】
受講料: 22,000円 (時期により変動)
学習期間: 3ヶ月
合格までの総学習時間: 約 120時間

学習継続率を上げる工夫:
・毎日、動画を1本だけ見るルール
・週1で過去問を1回だけ解く
・SNSで進捗を月1で公開 (=自己への約束)

「完璧に勉強しなきゃ」を捨てて、
「1日30分だけ続ける」に絞ったのが、
独学との違いでした。
```

## 6. 注意書き (約 100字)

```
※ 学習サービス利用にあたって。

・合格・取得には個人の努力・適性・継続が大きく影響します
・「○ヶ月で必ず合格」を保証するものではありません
・受講料・学習時間は私の場合の目安、講座・教材で変動します
・学習は「目的」が明確な方ほど続く傾向があります

不安な方は、無料体験・サンプル講座から始めるのもおすすめです。
```

## 10. 配信メモ

- ペルソナ B (副業会社員) との親和性高
- 簿記・FP は確定申告期 (1-3月) に CV ピーク
- プログラミングスクールは高単価だが CV ハードル高 → ローテで月1配信に留める
- しほさん本人の取得スキル (簿記) を軸にすると信頼度最大化
