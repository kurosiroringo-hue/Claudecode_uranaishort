# LP 雛形: 転職エージェント カテゴリ

ペルソナ B (副業 + キャリア悩み 30代会社員) 向けの高単価補助案件。
高単価 (1.2〜1.8万円) のため、月3〜5件 CV で大きく月収貢献。

> 景表法 遵守。「必ず転職成功」「年収1.5倍確実」NG。

---

## 1. ヘッドライン (3案)

```
A: 「転職するつもりがなかった私が、エージェントに登録した理由」
B: 「年収交渉が苦手な人ほど、エージェント面談すべき話」
C: 「副業を続けるか、転職するかで悩んだ夜の話」
```

---

## 2. 共感パート (約 200字)

```
こんばんは、しほです。

「転職、考えた方がいいのかな」
って、ふと思うこと、ありますか?

私はあります。
特に、賞与の通知を見たとき、
業界平均より明らかに低かった月。

ただ、「いま辞める勇気はない」「面接が怖い」「履歴書を書く時間がない」
で、3年スルーしてました。

「転職活動」と「転職」は別物だと
気づくのに、3年かかりました。
```

---

## 3. 解決パート (約 300字)

```
結論: 転職する/しないは別として、
「転職エージェントに登録しておく」のは早めにやって良かった。

理由は3つ:

①自分の市場価値を客観的に知れる
 → 求人 OK の年収レンジを聞けば、現職の妥当性が分かる

②応募・スケジュール管理を代行してくれる
 → 副業もある会社員には、時間効率が圧倒的に有利

③求職者側の費用負担なし
 → 利用者は無料、企業側からエージェントに報酬が払われる仕組み

私の場合、登録してから半年面談だけ受け、
今のところ転職はしていません。
それでも「市場価値を知れた」だけで、
今の仕事への向き合い方が変わりました。
```

---

## 4. 証拠パート (約 150字)

```
私が登録した3社の体験談:

【リクルートエージェント】
求人数が圧倒的に多い、年収レンジを正直に教えてくれる
→ 業界平均が分かる入門に最適

【doda】
非公開求人が多く、紹介の質が高め
→ 「ある程度方向性が決まってる」段階で有用

【マイナビエージェント】
20-30代向けの丁寧なサポート
→ 初めての転職活動には心強い

私の場合は、まず1社に絞らず3社に登録しました。
求人の幅・面談者との相性 を比較するため。
```

---

## 5. CTA (約 100字)

```
転職を考え始めた人、
情報収集だけでもしたい人に、
私が登録した3社のリンクを置いておきます ↓

【リクルートエージェント】[アフィリンク]
【doda】[アフィリンク]
【マイナビエージェント】[アフィリンク]

すべて登録無料、面談はオンライン可。

※ #PR を含みます。
```

---

## 6. 注意書き (約 100字)

```
※ 転職エージェント利用にあたって。

・登録 = 即面接 ではありません、まず面談 (情報収集) のみで OK
・紹介された求人を辞退するのは自由です
・複数社に登録しても問題ありません (一般的な利用法)
・転職の成否・年収アップは個人差・タイミングで大きく変動します

「いま転職する気がない」段階の登録も、十分価値があります。
```

## 8. A/B テスト 仮説

| 週 | 仮説 | 変更箇所 |
|---|---|---|
| 1 | ベースライン | 上記 |

| 4 | 証拠を「面談の流れ」具体化 | 不安解消強化 |

## 10. 配信メモ

- ペルソナ B (副業 30代会社員) と相性最高

- 「転職エージェント = 転職強要」イメージへの不安解消が CTR の鍵
