# LP 雛形: クレジットカード カテゴリ

ペルソナ A・B 双方に刺さりやすく、自己アフィ可能なものも多い。
LINE ステップ#5-6 で配信する補助案件。

> 景表法・特商法 遵守。「最強カード」「絶対作るべき」NG。

---

## 1. ヘッドライン (3案)

```
A: 「私が2枚運用に絞った理由 (年間42,000円ポイント獲得)」
B: 「クレカ7枚から2枚に減らしたら、家計が見えるようになった話」
C: 「自己アフィで8,000円もらった、最初の1枚」
```

---

## 2. 共感パート (約 200字)

```
こんばんは、しほです。

クレカ、何枚持ってますか?

私、20代の頃は7枚持ってました。
ファッション系のブランドカード、銀行系、ガソリン系…
「これは年会費無料だから」「これは特典が魅力」と
増やすたびに、家計が見えなくなっていきました。

明細を分散して見る面倒さで、
リボ払いに気づかず47万円残高ができてた時期も。

「クレカは多いほどお得」は、私の場合は嘘でした。
むしろ管理コストで損してました。
```

---

## 3. 解決パート (約 300字)

```
結論: クレカは2枚で十分です。

【メイン: 還元率1%以上の年会費無料カード】
私の場合、楽天カード。
楽天市場・楽天モバイルとセットでポイント効率化。

【サブ: 特定店舗で還元率3%以上のカード】
私の場合、三井住友カード(NL)。
コンビニ・飲食店で7%還元 (条件あり)。

この2枚運用で、年間獲得ポイントは約42,000円。

7枚持ってた頃と比べて:
・年会費がゼロ (3,000円分の節約)
・明細管理が圧倒的に楽
・ポイント分散の損失がなくなった

「枚数 = お得」じゃなく
「2枚に集中 = 効率化」が正解でした。
```

## 4. 証拠パート (約 150字)

```
2025年の年間ポイント獲得実績:

【楽天カード】
楽天市場での買い物中心、年間 約 28,000円分
(SPU で還元率 5〜10%超の月あり)

【三井住友カード(NL)】
コンビニ・飲食店利用中心、年間 約 14,000円分

合計: 42,000円分のポイント獲得。

家計の年間支出 約180万円中、ポイント還元率 2.3%。
「2枚に絞った」だけで、実質 2万円以上の家計改善でした。
```

## 6. 注意書き (約 100字)

```
※ クレジットカード利用にあたって。

・カード発行は審査があります、必ず承認されるとは限りません
・特典・還元率は申込時点の最新情報をカード会社サイトでご確認ください

・カードは3枚以上持つと管理が複雑化します、絞り込みをおすすめ

支出の管理が苦手な方は、現金 or デビットから始めてもOKです。
```

## 9. NG 表現チェック

- [ ] 「絶対作るべき」「最強」NG
- [ ] 「必ずポイントが○倍」NG
- [ ] 「年会費が永久無料」(変更可能性あり、案件規約要確認)
- [ ] 還元率の数字は **申込時点の正確な値** を ASP / カード会社で確認
- [ ] 「即日発行」「審査なし」NG (虚偽表示)
- [ ] アフィリンク前後に #PR
- [ ] 18歳以上発行 (未成年訴求NG)

---

## 10. 配信メモ

- 自己アフィ可案件が多いカテゴリ → ペルソナ B (副業会社員) の「初収入作り」にも応用可
- 年末 (ふるさと納税駆け込み)・新年度 (4月) はカード発行の波あり
- 楽天は楽天経済圏、三井住友は飲食店、それ以外を求めるならエポス・JCB W などをローテで紹介
