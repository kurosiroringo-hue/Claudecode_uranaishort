# 30万 → 100万 ロードマップ プレイブック (playbook-30to100.md)

月30万を達成した後、月100万に伸ばすための具体打ち手集。
**判断基準を数字で持つ** ことで、感覚論ではなく仮説検証で進める。

---

## 1. 30万 → 100万 の戦略仮説

### 構造変化

| 局面 | 月30万時点 (月6想定) | 月100万時点 (月12想定) |
|---|---|---|
| 主収益源 | 高単価1案件 (FX) | 5〜7案件のポートフォリオ |
| LINE リスト | 1,500人 | 8,000人 |
| 案件接触頻度 | ステップ#5 のみ | ステップ + 月次配信で複数案件 |
| Threads 投稿数/週 | 21 | 28 |
| 自社商品 | なし | note 月50件 (175,000円) |

### 100万到達のための **3つのレバー**

1. **LINE リスト規模を 1,500 → 8,000 (5.3倍)**
2. **案件ポートフォリオの分散** (1案件依存リスク回避 + 単価最適化)
3. **自社商品 (note) を月50件売る** (利益率高、ファンとの関係深化)

## 2. レバー① LINE リスト 5.3倍化

### サブ仮説

| サブ仮説 | アクション | 期待効果 |
|---|---|---|
| 特典 PDF を3種に分割するとペルソナ A/B/C ごとに刺さる | 既存PDFを3種に分割、Linktree でペルソナ選択肢提示 | 登録CVR 15% → 25% |
| Threads 投稿数を週21→28本に増やすとリスト純増数 比例 | 投稿頻度UP、X / note 転用比率を増やす | 月間登録数 ×1.3〜1.5 |
| 月1のキャンペーン (期間限定特典) で純増を一気に取る | 季節イベント (年末・NISA切替期) で追加PDF配布 | 月当たり ×1.2 |

### 実行ロードマップ (3〜6ヶ月)

```
[Month 7] 特典PDF 3種に分割、Linktree レイアウト変更
[Month 8] Threads 週28投稿 体制確立
[Month 9] LINE 配信を「ファネル分岐」 (投資 vs 副業) に
[Month 10] 季節キャンペーン (年末 NISA枠駆け込み)
[Month 11] X リアルタイム連動 (X バズを Threads で追撃)
[Month 12] 第3チャネル検証 (Instagram or YouTube Shorts)
```

## 3. レバー② 案件ポートフォリオ化

### 主軸 + 補助 + ローテの3層構造

| 層 | 案件数 | 月CV合計目標 | 例 |
|---|---|---|---|
| **主軸** | 1〜2 | 25件 | FX 口座、ネット証券 |
| **補助** | 2〜3 | 30件 | クレカ、転職、サブスク |
| **ローテ** | 3〜5 | 75件 | スクール、ふるさと納税、書籍、ポイ活、保険相談 |

### 案件差し替えの判断基準

#### EPC ベース (報酬 ÷ クリック)

| EPC | 判定 | アクション |
|---|---|---|
| 200円以上 | 主軸候補 | 露出を増やす (週2回 → 週3回) |
| 100〜200円 | 健全 | 現状維持 |
| 50〜100円 | 改善要 | LP・CTA を A/B テスト |
| 50円未満 | 差替候補 | 1ヶ月改善試行、改善なければ差替 |

#### 承認率 ベース

| 承認率 | 判定 | アクション |
|---|---|---|
| 70%以上 | 健全 | 維持 |
| 50〜70% | 注意 | ASP に否認理由ヒアリング |
| 50%未満 | 差替検討 | 案件依存度を50%以下に下げる、3ヶ月で差替 |

### 案件差し替え実例 (テンプレ)

```
[判断日] 2026-08-15
[対象案件] FX 案件A
[理由] 直近3ヶ月の承認率 45% (目標70%)、原因は取引条件の変更
[差替先] FX 案件B (取引条件 案件Aより緩い、単価同等)
[移行計画]
  Week 1: 案件Bの個別規約確認 + LP 雛形修正
  Week 2: LINE ステップ#5 を案件Bに差替
  Week 3: 効果測定開始
  Week 4-5: 比較してKPI改善見えなければ更に再考
```

## 4. レバー③ 自社商品 (note) の昇華

### なぜ自社商品か

- アフィリエイトは **ASP・案件・規約変更** の影響を受ける = 不安定収益源
- 自社商品 (note 有料記事) は **自分でコントロールできる** 安定収益
- ファンとの直接関係を作れる = アフィに頼らない収益化

### note 商品ロードマップ

| Phase | タイミング | 商品 | 価格 | 月販目標 |
|---|---|---|---|---|
| Phase 1 | 月7 | 「30代独身の老後資金 設計手順書」 | 1,000円 | 20部 |
| Phase 2 | 月8 | 「副業 月3万への道のり 全工程」 | 1,500円 | 15部 |
| Phase 3 | 月9 | 「家計改善 12ヶ月プラン」 | 1,500円 | 15部 |
| Phase 4 | 月10-12 | マガジン (上記3本 + 追加2本) | 月額500円 | 200人 |

### 月100万到達時の note 貢献額

```
Phase 1-3 単発: 50部 × 平均1,300円 = 65,000円
Phase 4 マガジン: 200人 × 500円 = 100,000円
合計: 165,000円 / 月 (月収100万円中の16.5%)
```

### 制作 → 販売のループ

```
1. Threads / LINE で予告投稿 (有料化 1ヶ月前から)
2. 既存 LINE リストに優先案内 (15% OFF クーポン)
3. リリース後 1週間で集中プロモ
4. その後は LINE ステップに「卒業段階で note へ」誘導
5. レビュー・評価を集めて改善
```

## 5. LINE ステップ A/B テスト 設計

### 検証順序 (優先度順)

| # | テスト対象 | 仮説 | 測定指標 |
|---|---|---|---|
| 1 | ステップ#1 (お礼 + 特典) | 件名にペルソナ別の数字を入れると開封率 +10% | 開封率 |
| 2 | ステップ#3 (教育①) | 失敗ストーリー先 vs 知識先で完走率が変わる | ステップ完走率 |
| 3 | ステップ#5 (案件提案) | 「失敗回避」軸 vs 「成功体験」軸で クリック率変動 | クリック率 |
| 4 | ステップ#7 (note誘導) | 単価500円 vs 1,000円で 売上対人数比 | 購入率 |

### A/B テスト 実行ルール

- **同時並行は最大2つまで** (要因切り分け不可になる)
- 各テストは **最低500人のリスト** で実施 (統計有意性)
- テスト期間: 2週間
- 結果が出たら勝ちパターンに統合 → 次のテストへ

## 6. 第3チャネル展開判断

### 候補と相性

| チャネル | 適合度 | 想定 ROI | 推奨タイミング |
|---|---|---|---|
| Instagram | ★★★★☆ | 中 (ストーリーズ + ハイライト) | 月8 |
| YouTube Shorts | ★★★★★ | 高 (検索性 + 長期蓄積) | 月10 |
| TikTok | ★★★☆☆ | 中 (顔出し+動画必要、本人の心理障壁) | 月12 以降 |
| Pinterest | ★★☆☆☆ | 低 (家計簿系 NISA系で弱り目) | 当面なし |

### 判断基準

```
Threads 月間インプレ 50万超 + LINE 月間登録 500人 安定後 → 第3チャネル検討
```

逆に Threads がまだ伸び続けてるなら、第3チャネルは後回し。
**1チャネルを 100% にするより、2チャネルが各 50% のほうが時間効率は悪い**。

## 7. 想定リスクと対策

| リスク | 想定確率 | 影響 | 対策 |
|---|---|---|---|
| ステマ規制違反による措置命令 | 低 | 最大 | 投稿前の自動コンプラチェック、LINE 配信前の手動再確認 |
| 主軸案件 (FX) の承認停止・終了 | 中 | 大 | 案件分散 (主軸2本)、半年に1回 ASP 全棚卸し |
| Threads アルゴリズム変動でリーチ激減 | 中 | 大 | LINE リストへの恒常的なシフト、第3チャネル準備 |
| LINE 解除率 急増 | 低 | 中 | 月次でステップ配信を見直し、配信頻度を「読者ペース」に |
| 個人情報漏洩・LINE アカウント凍結 | 低 | 最大 | 二要素認証、個人情報を不必要に集めない、他者からの相談記録の暗号化 |

## 8. 「100万到達した」と判断する基準

以下が **3ヶ月連続** で達成されたら「月100万到達」と判定する:

- [ ] 月収 (確定額、否認後) 100万円以上
- [ ] 単一案件への依存度 50% 以下
- [ ] LINE リスト 7,000人以上、解除率 5%以下
- [ ] Threads フォロワー 18,000人以上
- [ ] 自社商品 (note) 月10万円以上の売上
- [ ] コンプラ違反 0件 (3ヶ月)

単月達成だけでは不安定なので、**3ヶ月連続** を最低ラインに。

## 9. 100万 達成後の戦略仮説 (次の地平)

### 候補ルート

#### A. 月150万円ルート (アフィ深堀)

- 主軸案件をさらに最適化、EPC 2倍化
- 第3チャネル (Instagram or YouTube Shorts) を伸ばす
- 12ヶ月で達成可能

#### B. 月100万 + 自社商品強化ルート (利益率重視)

- アフィは 60万円で安定、note + 個別コンサル で 40万円
- 利益率が高い (アフィは入金まで2-3ヶ月、自社は即日)
- 12ヶ月でファン化された読者を 1,000人 育てる

#### C. 法人化 + チーム化ルート (時間効率)

- 月100万を超えたら税効果と時間効率で法人化検討
- 投稿生成・LINE 配信を外注化、自分は戦略・コンテンツ監修
- 月150万〜200万へ拡大

> どのルートを選ぶかは、しほさん本人の **生活設計** (yuru-FIRE 思想) に合わせて選択する。
> 「最大化」が目的ではないので、月100万達成後は **生活の質との両立** を最優先。
